A2. Solución por método gráfico

A1 FormulaciónA2 GráficoA3 SimplexA4 SolverA5 PythonA6 Sensibilidad

Competencia: Resolver modelos de dos variables mediante región factible, vértices y evaluación de la función objetivo.

Guía de aprendizaje

  • Usar el método gráfico solo cuando existan dos variables de decisión.
  • Convertir cada restricción en recta para encontrar interceptos.
  • Determinar el semiplano factible con un punto de prueba.
  • Identificar todos los vértices de la región factible.
  • Evaluar la función objetivo en cada vértice.
  • Reconocer casos especiales: no factible, no acotado y múltiples óptimos.

Buenas prácticas y errores comunes

  • Dibujar con escala coherente.
  • No evaluar puntos fuera de la región factible.
  • En minimización con restricciones >=, revisar que la región suele quedar alejada del origen.
  • Si la FO es paralela a una frontera activa, puede haber infinitas soluciones óptimas.

PL-SEC2-EJ01

Maximización con dos restricciones

Planteamiento

Una fábrica produce A y B. Cada A deja 40 y cada B deja 30. A usa 2 h de máquina y 1 h de ensamble; B usa 1 h de máquina y 1 h de ensamble. Hay 100 h de máquina y 80 h de ensamble.

Datos

ProductoUtilidadMáquinaEnsamble
A4021
B3011
Disponibilidad—10080

Variables de decisión

x = unidades de A; y = unidades de B.

Función objetivo

Max Z = 40x + 30y

Restricciones

2x + y <= 100
x + y <= 80
x,y >= 0

Dominio

x,y >= 0.

Método / procedimiento

Se dibujan las rectas, se identifica la región factible y se evalúan los vértices.

Solución

Vértices: (0,0), (50,0), (20,60), (0,80). Valores Z: 0, 2000, 2600, 2400. Óptimo: x=20, y=60, Z=2600.

Interpretación

La mezcla óptima usa completamente máquina y ensamble.

Verificación

2(20)+60=100; 20+60=80.

PL-SEC2-EJ02

Minimización acotada de dieta

Planteamiento

Se combinan dos alimentos para alcanzar proteína y calorías mínimas al menor costo.

Datos

AlimentoCostoProteínaCalorías
A23100
B32200
Mínimo—18900

Variables de decisión

x = porciones de A; y = porciones de B.

Función objetivo

Min C = 2x + 3y

Restricciones

3x + 2y >= 18
100x + 200y >= 900
x,y >= 0

Dominio

x,y >= 0.

Método / procedimiento

Para minimización con >=, la región factible queda por encima de las rectas. Se evalúan los vértices factibles más cercanos al origen.

Solución

Intersección: 3x+2y=18 y x+2y=9. Restando: 2x=9, x=4.5, y=2.25. Costo=15.75. Vértices de ejes factibles: (9,0) costo 18; (0,9) costo 27. Óptimo: (4.5,2.25).

Interpretación

La combinación mixta es más barata que usar un solo alimento.

Verificación

Proteína=18; calorías=900.

PL-SEC2-EJ03

Restricción redundante

Planteamiento

Una operación tiene tres restricciones, pero una no cambia la región factible.

Datos

RestricciónForma
R1x + y <= 10
R22x + 2y <= 24
R3x <= 7

Variables de decisión

x,y = cantidades a producir.

Función objetivo

Max Z = 5x + 4y

Restricciones

x + y <= 10
2x + 2y <= 24
x <= 7
x,y >= 0

Dominio

x,y >= 0.

Método / procedimiento

R2 equivale a x+y<=12, por tanto es menos estricta que R1 y resulta redundante.

Solución

Vértices relevantes: (0,0), (7,0), (7,3), (0,10). Valores: 0,35,47,40. Óptimo: x=7,y=3,Z=47.

Interpretación

La restricción redundante puede omitirse sin cambiar la solución.

Verificación

R2: 2(7)+2(3)=20<=24.

PL-SEC2-EJ04

Múltiples óptimos

Planteamiento

Un modelo presenta una función objetivo paralela a una frontera activa.

Datos

ElementoValor
UtilidadZ=2x+2y
Capacidadx+y<=10
Límite xx<=8

Variables de decisión

x,y = unidades de dos productos sustitutos.

Función objetivo

Max Z = 2x + 2y

Restricciones

x + y <= 10
x <= 8
y <= 9
x,y >= 0

Dominio

x,y >= 0.

Método / procedimiento

La recta objetivo 2x+2y es paralela a x+y=10.

Solución

Todo punto factible sobre el segmento x+y=10 con 1<=x<=8 es óptimo. Por ejemplo (8,2), (5,5), (1,9). Z=20.

Interpretación

La empresa tiene flexibilidad operativa sin sacrificar utilidad.

Verificación

Todos los puntos cumplen x+y=10 y producen Z=20.

PL-SEC2-EJ05

Modelo no factible

Planteamiento

Una empresa exige producción mínima total mayor que la capacidad máxima permitida.

Datos

CondiciónRestricción
Demanda mínimax+y>=50
Capacidadx+y<=30

Variables de decisión

x,y = unidades de dos productos.

Función objetivo

Max Z = 10x + 8y

Restricciones

x + y >= 50
x + y <= 30
x,y >= 0

Dominio

x,y >= 0.

Método / procedimiento

Se grafican ambas semirrectas; no existe intersección entre x+y>=50 y x+y<=30.

Solución

No hay región factible; el problema es infeasible.

Interpretación

Las metas son incompatibles con la capacidad disponible.

Verificación

Ningún par (x,y) puede sumar simultáneamente al menos 50 y máximo 30.

PL-SEC2-EJ06

Modelo no acotado

Planteamiento

Un modelo permite aumentar indefinidamente la función objetivo porque no hay restricción superior suficiente.

Datos

ElementoValor
FOMax Z=x+y
Restricciónx-y>=2

Variables de decisión

x,y = variables de decisión.

Función objetivo

Max Z = x + y

Restricciones

x - y >= 2
x,y >= 0

Dominio

x,y >= 0.

Método / procedimiento

La región factible se extiende indefinidamente hacia valores grandes de x e y.

Solución

No existe valor máximo finito. Por ejemplo, si y=t y x=t+2, Z=2t+2, que crece sin límite.

Interpretación

Falta una restricción de capacidad o presupuesto que limite el crecimiento.

Verificación

Para cualquier t>=0, (t+2,t) es factible.

Mezcla con dos recursos

Se producen dos mezclas químicas con disponibilidad de materia prima A y B.

Datos

Restricciones

2x + 4y <= 160

PL-SEC2-EJ09

Dieta con dos alimentos

Planteamiento

Una dieta usa avena y huevo para cumplir proteína y energía al mínimo costo.

Datos

AlimentoCostoProteínaEnergía
Avena15150
Huevo212100
Mínimo—36600

Variables de decisión

x = porciones de avena; y = porciones de huevo.

Función objetivo

Min C = x + 2y

Restricciones

5x + 12y >= 36
150x + 100y >= 600
x,y >= 0

Dominio

x,y >= 0.

Método / procedimiento

Evaluar vértices factibles de la región superior.

Solución

Intersección: 5x+12y=36 y 3x+2y=12. De la segunda x=4-2y/3; sustituyendo: 20 -10y/3 +12y=36 => 26y/3=16 => y=1.846, x=2.769. Costo=6.461. Ejes: (7.2,0) costo 7.2; (0,6) costo 12. Óptimo intersección.

Interpretación

La combinación aprovecha avena barata para energía y huevo para proteína.

Verificación

Proteína y energía cumplen exactamente.
