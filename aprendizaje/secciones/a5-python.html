A5. Resolver Programación Lineal con Python

A1 FormulaciónA2 GráficoA3 SimplexA4 SolverA5 PythonA6 Sensibilidad

Competencia: implementar, resolver, validar y documentar modelos de PL en Python usando PuLP como herramienta principal y scipy.optimize.linprog como alternativa matricial.

Teoría ampliada: del modelo matemático al código

Programar un modelo de Programación Lineal en Python no consiste en “traducir ciegamente” ecuaciones. Primero se debe tener un modelo matemático correcto; luego se implementan conjuntos, parámetros, variables, función objetivo y restricciones. Python es especialmente útil cuando el modelo tiene muchos datos, múltiples índices o debe repetirse para escenarios.

PuLP: recomendado para aprendizaje por su sintaxis declarativa: variables, objetivo y restricciones se parecen al modelo matemático.
scipy.optimize.linprog: alternativa matricial útil para entender la forma estándar computacional: vectores c, matrices A y vector b.

Instalación sugerida

pip install pulp scipy pandas openpyxl

Guía detallada paso a paso

  1. Escriba el modelo en papel: variables, FO, restricciones y dominio.
  2. Identifique datos: coeficientes, capacidades, demandas, costos, beneficios.
  3. Defina el problema: LpProblem(nombre, LpMaximize/LpMinimize).
  4. Cree variables: con límites inferiores, superiores y tipo si aplica.
  5. Agregue función objetivo: una expresión lineal.
  6. Agregue restricciones: una por condición del modelo.
  7. Resuelva: con el solver disponible.
  8. Lea estado: óptimo, infactible, no acotado u otro.
  9. Extraiga resultados: valores de variables, FO, holguras y duales si el solver lo permite.
  10. Valide: calcule manualmente consumos y verifique restricciones.

Plantilla base PuLP

import pulp as pl

model = pl.LpProblem("modelo_pl", pl.LpMaximize)
x = pl.LpVariable("x", lowBound=0)
y = pl.LpVariable("y", lowBound=0)

model += 40*x + 30*y, "Objetivo"
model += 2*x + y <= 100, "Maquina"
model += x + y <= 80, "Ensamble"

status = model.solve(pl.PULP_CBC_CMD(msg=False))
print(pl.LpStatus[status])
print(x.varValue, y.varValue, pl.value(model.objective))

PL-SEC5-EJ02

Dieta mínima

Modelo

Min C con alimentos y nutrientes mínimos

Código principal

import pulp as pl
foods=['A','B']; cost={'A':2,'B':3}; prot={'A':3,'B':2}; cal={'A':100,'B':200}
m=pl.LpProblem('dieta', pl.LpMinimize)
x=pl.LpVariable.dicts('porciones', foods, lowBound=0)
m += pl.lpSum(cost[i]*x[i] for i in foods)
m += pl.lpSum(prot[i]*x[i] for i in foods) >= 18
m += pl.lpSum(cal[i]*x[i] for i in foods) >= 900
m.solve(pl.PULP_CBC_CMD(msg=False))

PL-SEC5-EJ04

Transporte

Modelo

Min costo desde plantas a mercados

Código principal

import pulp as pl
plants=['P1','P2']; markets=['M1','M2','M3']
supply={'P1':80,'P2':70}; demand={'M1':50,'M2':60,'M3':40}
cost={('P1','M1'):4,('P1','M2'):6,('P1','M3'):8,('P2','M1'):5,('P2','M2'):4,('P2','M3'):3}
m=pl.LpProblem('transporte', pl.LpMinimize)
x=pl.LpVariable.dicts('envio',(plants,markets),lowBound=0)
m += pl.lpSum(cost[i,j]*x[i][j] for i in plants for j in markets)
for i in plants: m += pl.lpSum(x[i][j] for j in markets) <= supply[i]
for j in markets: m += pl.lpSum(x[i][j] for i in plants) >= demand[j]
m.solve(pl.PULP_CBC_CMD(msg=False))

PL-SEC5-EJ06

Cartera

Modelo

Max retorno con riesgo promedio máximo

Código principal

import pulp as pl
assets=['acciones','bonos','efectivo']; ret={'acciones':0.12,'bonos':0.07,'efectivo':0.03}; risk={'acciones':0.20,'bonos':0.08,'efectivo':0.01}
m=pl.LpProblem('cartera', pl.LpMaximize)
w=pl.LpVariable.dicts('peso', assets, lowBound=0, upBound=0.7)
m += pl.lpSum(ret[a]*w[a] for a in assets)
m += pl.lpSum(w[a] for a in assets) == 1
m += pl.lpSum(risk[a]*w[a] for a in assets) <= 0.10
m.solve(pl.PULP_CBC_CMD(msg=False))

Planeación de turnos

Modelo

Min costo cubriendo demanda por franja

Código principal

import pulp as pl
shifts=['T1','T2','T3']; periods=['M','T','N']
cost={'T1':90,'T2':100,'T3':110}; demand={'M':8,'T':10,'N':6}
cover={('T1','M'):1,('T1','T'):1,('T1','N'):0,('T2','M'):0,('T2','T'):1,('T2','N'):1,('T3','M'):1,('T3','T'):0,('T3','N'):1}
m=pl.LpProblem('turnos', pl.LpMinimize)
x=pl.LpVariable.dicts('empleados', shifts, lowBound=0)
m += pl.lpSum(cost[s]*x[s] for s in shifts)
for p in periods: m += pl.lpSum(cover[s,p]*x[s] for s in shifts) >= demand[p]
m.solve(pl.PULP_CBC_CMD(msg=False))

res=linprog(c,A_ub=A_ub,b_ub=b_ub,bounds=[(0,None),(0,None)],method='highs')

Validación automática

Modelo

Chequeo programático de restricciones

Código principal

def validar(x,y):
    checks={
      'maquina': 2*x+y <= 100 + 1e-6,
      'ensamble': x+y <= 80 + 1e-6,
      'no_negatividad': x >= -1e-6 and y >= -1e-6
    }
    return checks
print(validar(20,60))
