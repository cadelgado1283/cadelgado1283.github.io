A5. Resolver Programación Lineal con Python

A1 Formulación A2 Gráfico A3 Simplex A4 Solver A5 Python A6 Sensibilidad

Competencia: formular, implementar, resolver, validar e interpretar modelos de Programación Lineal en Python usando PuLP como herramienta principal y scipy.optimize.linprog como alternativa matricial.

1. ¿Por qué resolver Programación Lineal con Python?

Python permite resolver modelos de Programación Lineal de forma reproducible, auditable y escalable. A diferencia de una hoja de cálculo, el modelo queda documentado en código: los conjuntos, parámetros, variables, función objetivo, restricciones, solución y validación pueden revisarse línea por línea. Esto es especialmente útil cuando se trabaja con muchos productos, plantas, periodos, escenarios o fuentes de datos.

PuLP: recomendado para aprender porque su sintaxis se parece a la formulación matemática: variables, objetivo y restricciones se escriben casi como ecuaciones.
linprog: recomendado como alternativa para comprender la forma matricial computacional: vector de costos, matriz de restricciones y vector de recursos.

2. Flujo correcto: del problema al código

  1. Comprender el problema: identificar la decisión, los recursos, costos, beneficios, demandas y límites.
  2. Definir variables: declarar qué representa cada variable y en qué unidad se mide.
  3. Formular el modelo matemático: escribir función objetivo, restricciones y dominio antes de programar.
  4. Codificar parámetros: crear diccionarios, listas o tablas con los datos del problema.
  5. Crear el modelo en PuLP: elegir maximización o minimización.
  6. Crear variables en Python: usar variables simples o diccionarios de variables si hay índices.
  7. Agregar objetivo y restricciones: traducir cada ecuación matemática a una expresión lineal.
  8. Resolver: llamar al solver y revisar el estado devuelto.
  9. Interpretar: extraer valores óptimos, valor objetivo, uso de recursos, holguras y cumplimiento de restricciones.
  10. Validar: calcular manualmente los lados izquierdos de las restricciones para evitar errores de transcripción.

Convención de notación matemática usada en A5

Para que el paso del modelo matemático al código Python sea claro, todas las ecuaciones de esta sección se presentan en bloques estructurados. Los subíndices identifican productos, alimentos, activos, plantas, mercados o turnos; las sumatorias representan agregaciones sobre conjuntos; y cada restricción incluye, cuando corresponde, una nota de interpretación.

Maximizar Z = ∑i cixi

xi ≥ 0 dominio de no negatividad

4. Plantilla general en PuLP

# Importa PuLP, la librería que permite crear y resolver modelos de Programación Lineal.
import pulp as pl

# Crea un modelo de maximización llamado "modelo_base".
modelo = pl.LpProblem("modelo_base", pl.LpMaximize)

# Crea una variable de decisión x no negativa.
x = pl.LpVariable("x", lowBound=0)

# Crea una variable de decisión y no negativa.
y = pl.LpVariable("y", lowBound=0)

# Agrega la función objetivo al modelo.
modelo += 40*x + 30*y, "Utilidad_total"

# Agrega la primera restricción de capacidad.
modelo += 2*x + y <= 100, "Capacidad_maquina"

# Agrega la segunda restricción de capacidad.
modelo += x + y <= 80, "Capacidad_ensamble"

# Resuelve el modelo con el solver CBC incluido en PuLP y oculta mensajes técnicos.
estado = modelo.solve(pl.PULP_CBC_CMD(msg=False))

# Imprime el estado de solución, por ejemplo Optimal, Infeasible o Unbounded.
print("Estado:", pl.LpStatus[estado])

# Imprime los valores óptimos de las variables.
print("x =", x.varValue)
print("y =", y.varValue)

# Imprime el valor óptimo de la función objetivo.
print("Valor objetivo =", pl.value(modelo.objective))

PL-SEC5-EJ01

Producción de dos productos

Planteamiento del problema

Una empresa fabrica dos productos: A y B. Cada unidad de A genera una utilidad de 40 unidades monetarias y cada unidad de B genera 30. El producto A requiere 2 horas de máquina y 1 hora de ensamble. El producto B requiere 1 hora de máquina y 1 hora de ensamble. La empresa dispone de 100 horas de máquina y 80 horas de ensamble por semana. Se desea determinar cuántas unidades de cada producto fabricar para maximizar la utilidad total.

ProductoUtilidadMáquinaEnsamble
A4021
B3011
Disponible—10080

Modelo matemático

Variables:

xA = unidades del producto A a fabricar
xB = unidades del producto B a fabricar

Función objetivo:

Maximizar Z = 40xA + 30xB

Restricciones:

2xA + xB ≤ 100 (horas de máquina)
xA + xB ≤ 80 (horas de ensamble)
xA, xB ≥ 0

Código Python explicado línea por línea

# Importa la librería PuLP y la renombra como pl para escribir menos código.
import pulp as pl

# Crea un modelo de maximización llamado "produccion_dos_productos".
modelo = pl.LpProblem("produccion_dos_productos", pl.LpMaximize)

# Crea la variable x_A, que representa unidades del producto A, con límite inferior 0.
x_A = pl.LpVariable("x_A_producto_A", lowBound=0)

# Crea la variable x_B, que representa unidades del producto B, con límite inferior 0.
x_B = pl.LpVariable("x_B_producto_B", lowBound=0)

# Agrega la función objetivo: maximizar la utilidad total de A y B.
modelo += 40*x_A + 30*x_B, "Utilidad_total"

# Agrega la restricción de horas de máquina disponibles.
modelo += 2*x_A + x_B <= 100, "Horas_maquina"

# Agrega la restricción de horas de ensamble disponibles.
modelo += x_A + x_B <= 80, "Horas_ensamble"

# Resuelve el modelo usando CBC, el solver incluido con PuLP.
estado = modelo.solve(pl.PULP_CBC_CMD(msg=False))

# Muestra si el solver encontró una solución óptima.
print("Estado:", pl.LpStatus[estado])

# Muestra cuántas unidades de A deben producirse.
print("Producto A:", x_A.varValue)

# Muestra cuántas unidades de B deben producirse.
print("Producto B:", x_B.varValue)

# Muestra la utilidad máxima obtenida.
print("Utilidad máxima:", pl.value(modelo.objective))

# Calcula el uso real de horas de máquina con la solución encontrada.
uso_maquina = 2*x_A.varValue + x_B.varValue

# Calcula el uso real de horas de ensamble con la solución encontrada.
uso_ensamble = x_A.varValue + x_B.varValue

# Imprime la validación de recursos usados frente a recursos disponibles.
print("Uso máquina:", uso_maquina, "/ 100")
print("Uso ensamble:", uso_ensamble, "/ 80")

Resultado e interpretación

El resultado esperado es x_A = 20, x_B = 60 y Z = 2600. La empresa debe producir 20 unidades de A y 60 unidades de B. Ambas restricciones quedan activas: se usan 100 horas de máquina y 80 de ensamble.

PL-SEC5-EJ02

Dieta de costo mínimo

Planteamiento del problema

Un nutricionista desea diseñar una dieta usando dos alimentos. El alimento A cuesta 2 unidades monetarias por porción, aporta 3 unidades de proteína y 100 calorías. El alimento B cuesta 3 unidades monetarias por porción, aporta 2 unidades de proteína y 200 calorías. La dieta debe aportar al menos 18 unidades de proteína y 900 calorías. Se desea minimizar el costo total.

AlimentoCostoProteínaCalorías
A23100
B32200
Mínimo—18900

Modelo matemático

xA = porciones del alimento A
xB = porciones del alimento B
Minimizar C = 2xA + 3xB
3xA + 2xB ≥ 18 (proteína mínima)
100xA + 200xB ≥ 900 (calorías mínimas)
xA, xB ≥ 0

Código Python explicado línea por línea

# Importa PuLP para construir y resolver el modelo lineal.
import pulp as pl

# Define la lista de alimentos disponibles.
alimentos = ["A", "B"]

# Define el costo por porción de cada alimento.
costo = {"A": 2, "B": 3}

# Define el aporte de proteína por porción de cada alimento.
proteina = {"A": 3, "B": 2}

# Define el aporte calórico por porción de cada alimento.
calorias = {"A": 100, "B": 200}

# Crea un modelo de minimización porque se desea reducir el costo total.
modelo = pl.LpProblem("dieta_costo_minimo", pl.LpMinimize)

# Crea una variable no negativa para las porciones de cada alimento.
x = pl.LpVariable.dicts("porciones", alimentos, lowBound=0)

# Agrega la función objetivo: costo total de la dieta.
modelo += pl.lpSum(costo[i]*x[i] for i in alimentos), "Costo_total"

# Agrega la restricción de proteína mínima requerida.
modelo += pl.lpSum(proteina[i]*x[i] for i in alimentos) >= 18, "Proteina_minima"

# Agrega la restricción de calorías mínimas requeridas.
modelo += pl.lpSum(calorias[i]*x[i] for i in alimentos) >= 900, "Calorias_minimas"

# Resuelve el modelo con el solver CBC.
estado = modelo.solve(pl.PULP_CBC_CMD(msg=False))

# Imprime el estado de la solución.
print("Estado:", pl.LpStatus[estado])

# Recorre cada alimento e imprime la cantidad óptima de porciones.
for i in alimentos:
    print(i, "=", x[i].varValue)

# Imprime el costo mínimo de la dieta.
print("Costo mínimo:", pl.value(modelo.objective))

# Calcula el total de proteína aportado por la solución.
proteina_total = sum(proteina[i]*x[i].varValue for i in alimentos)

# Calcula el total de calorías aportado por la solución.
calorias_total = sum(calorias[i]*x[i].varValue for i in alimentos)

# Imprime los aportes para verificar que cumplen los mínimos.
print("Proteína total:", proteina_total)
print("Calorías totales:", calorias_total)

Resultado e interpretación

La solución esperada es A = 4.5, B = 2.25, con costo mínimo 15.75. Ambas restricciones nutricionales quedan exactamente satisfechas.

PL-SEC5-EJ03

Mezcla de fertilizantes

Planteamiento del problema

Una empresa agrícola prepara un fertilizante mezclando dos materias primas: M1 y M2. Cada kilogramo de M1 cuesta 6 y aporta 4 unidades de nitrógeno y 2 de fósforo. Cada kilogramo de M2 cuesta 5 y aporta 2 unidades de nitrógeno y 5 de fósforo. El lote final debe aportar al menos 80 unidades de nitrógeno y 70 unidades de fósforo. Se desea minimizar el costo de la mezcla.

Materia primaCostoNitrógenoFósforo
M1642
M2525
Requerimiento—8070

Modelo matemático

x1 = kg de materia prima M1
x2 = kg de materia prima M2
Minimizar C = 6x1 + 5x2
4x1 + 2x2 ≥ 80 (nitrógeno)
2x1 + 5x2 ≥ 70 (fósforo)
x1, x2 ≥ 0

Código Python explicado línea por línea

# Importa PuLP.
import pulp as pl

# Define las materias primas disponibles.
materias = ["M1", "M2"]

# Define el costo por kg de cada materia prima.
costo = {"M1": 6, "M2": 5}

# Define el aporte de nitrógeno por kg.
nitrogeno = {"M1": 4, "M2": 2}

# Define el aporte de fósforo por kg.
fosforo = {"M1": 2, "M2": 5}

# Crea el modelo de minimización.
modelo = pl.LpProblem("mezcla_fertilizantes", pl.LpMinimize)

# Crea una variable no negativa para los kg de cada materia prima.
x = pl.LpVariable.dicts("kg", materias, lowBound=0)

# Define la función objetivo: minimizar costo total de materias primas.
modelo += pl.lpSum(costo[i]*x[i] for i in materias), "Costo_total"

# Restricción de nitrógeno mínimo requerido.
modelo += pl.lpSum(nitrogeno[i]*x[i] for i in materias) >= 80, "Nitrogeno_minimo"

# Restricción de fósforo mínimo requerido.
modelo += pl.lpSum(fosforo[i]*x[i] for i in materias) >= 70, "Fosforo_minimo"

# Resuelve el modelo.
estado = modelo.solve(pl.PULP_CBC_CMD(msg=False))

# Imprime estado, cantidades óptimas y costo.
print("Estado:", pl.LpStatus[estado])
for i in materias:
    print(i, "=", x[i].varValue)
print("Costo mínimo:", pl.value(modelo.objective))

# Calcula el aporte total de cada nutriente para validar restricciones.
print("Nitrógeno:", sum(nitrogeno[i]*x[i].varValue for i in materias))
print("Fósforo:", sum(fosforo[i]*x[i].varValue for i in materias))

Resultado e interpretación

La solución óptima combina ambas materias primas para cumplir los nutrientes al menor costo. La validación debe mostrar nitrógeno y fósforo iguales o superiores a los requerimientos.

PL-SEC5-EJ04

Transporte desde plantas a mercados

Planteamiento del problema

Una compañía tiene dos plantas que abastecen tres mercados. La planta P1 puede enviar hasta 80 unidades y la planta P2 hasta 70. Los mercados M1, M2 y M3 demandan 50, 60 y 40 unidades, respectivamente. Se conocen los costos unitarios de envío desde cada planta a cada mercado. Se desea minimizar el costo total de transporte cumpliendo toda la demanda sin superar la oferta de cada planta.

Origen/DestinoM1M2M3Oferta
P146880
P254370
Demanda506040150

Modelo matemático

xij = unidades enviadas desde planta i hasta mercado j
Minimizar C = ∑i ∑j cijxij
∑j xij ≤ Ofertai ∀ i
∑i xij ≥ Demandaj ∀ j
xij ≥ 0

Código Python explicado línea por línea

# Importa PuLP.
import pulp as pl

# Define el conjunto de plantas.
plantas = ["P1", "P2"]

# Define el conjunto de mercados.
mercados = ["M1", "M2", "M3"]

# Define la oferta máxima disponible en cada planta.
oferta = {"P1": 80, "P2": 70}

# Define la demanda mínima de cada mercado.
demanda = {"M1": 50, "M2": 60, "M3": 40}

# Define el costo unitario de transporte para cada ruta planta-mercado.
costo = {
    ("P1", "M1"): 4, ("P1", "M2"): 6, ("P1", "M3"): 8,
    ("P2", "M1"): 5, ("P2", "M2"): 4, ("P2", "M3"): 3
}

# Crea el modelo de minimización del costo total de transporte.
modelo = pl.LpProblem("transporte_plantas_mercados", pl.LpMinimize)

# Crea variables x[i][j] para cada combinación planta-mercado.
x = pl.LpVariable.dicts("envio", (plantas, mercados), lowBound=0)

# Define la función objetivo como la suma de costos unitarios por cantidades enviadas.
modelo += pl.lpSum(costo[i, j]*x[i][j] for i in plantas for j in mercados), "Costo_total"

# Agrega restricciones de oferta para cada planta.
for i in plantas:
    modelo += pl.lpSum(x[i][j] for j in mercados) <= oferta[i], f"Oferta_{i}"

# Agrega restricciones de demanda para cada mercado.
for j in mercados:
    modelo += pl.lpSum(x[i][j] for i in plantas) >= demanda[j], f"Demanda_{j}"

# Resuelve el modelo.
estado = modelo.solve(pl.PULP_CBC_CMD(msg=False))

# Imprime estado y costo total mínimo.
print("Estado:", pl.LpStatus[estado])
print("Costo mínimo:", pl.value(modelo.objective))

# Imprime únicamente las rutas usadas con envío positivo.
for i in plantas:
    for j in mercados:
        if x[i][j].varValue > 1e-6:
            print(i, "->", j, "=", x[i][j].varValue)

# Valida la oferta usada por cada planta.
for i in plantas:
    print("Uso oferta", i, sum(x[i][j].varValue for j in mercados), "/", oferta[i])

# Valida la demanda cubierta por cada mercado.
for j in mercados:
    print("Cobertura demanda", j, sum(x[i][j].varValue for i in plantas), "/", demanda[j])

Resultado e interpretación

El modelo asigna envíos a las rutas más económicas respetando oferta y demanda. La validación permite comprobar que ninguna planta excede su capacidad y que todos los mercados quedan abastecidos.

PL-SEC5-EJ05

Selección de medios publicitarios

Planteamiento del problema

Una empresa desea distribuir su campaña entre radio, redes sociales y prensa. Cada anuncio en radio cuesta 800 y genera 5000 impactos; cada anuncio en redes cuesta 400 y genera 3000 impactos; cada anuncio en prensa cuesta 350 y genera 2500 impactos. El presupuesto máximo es 10 000. Por estrategia, se deben contratar al menos 2 anuncios de radio y como máximo 15 anuncios en redes. Se desea maximizar los impactos totales.

MedioCostoImpactosLímite
Radio8005000mín. 2
Redes4003000máx. 15
Prensa3502500sin límite

Modelo matemático

xR, xS, xP = número de anuncios en radio, redes y prensa
Maximizar I = 5000xR + 3000xS + 2500xP
800xR + 400xS + 350xP ≤ 10000
xR ≥ 2
xS ≤ 15
xR, xS, xP ≥ 0

Código Python explicado línea por línea

# Importa PuLP.
import pulp as pl

# Define los medios publicitarios disponibles.
medios = ["radio", "redes", "prensa"]

# Define el costo por anuncio en cada medio.
costo = {"radio": 800, "redes": 400, "prensa": 350}

# Define los impactos estimados por anuncio en cada medio.
impactos = {"radio": 5000, "redes": 3000, "prensa": 2500}

# Crea un modelo de maximización de impactos.
modelo = pl.LpProblem("plan_medios", pl.LpMaximize)

# Crea variables continuas no negativas para anuncios por medio.
x = pl.LpVariable.dicts("anuncios", medios, lowBound=0)

# Define la función objetivo como impactos totales.
modelo += pl.lpSum(impactos[m]*x[m] for m in medios), "Impactos_totales"

# Agrega la restricción de presupuesto máximo.
modelo += pl.lpSum(costo[m]*x[m] for m in medios) <= 10000, "Presupuesto"

# Agrega la restricción estratégica de mínimo de radio.
modelo += x["radio"] >= 2, "Minimo_radio"

# Agrega la restricción estratégica de máximo de redes.
modelo += x["redes"] <= 15, "Maximo_redes"

# Resuelve el modelo.
estado = modelo.solve(pl.PULP_CBC_CMD(msg=False))

# Imprime estado, anuncios por medio e impactos máximos.
print("Estado:", pl.LpStatus[estado])
for m in medios:
    print(m, "=", x[m].varValue)
print("Impactos máximos:", pl.value(modelo.objective))

# Valida cuánto presupuesto fue utilizado.
presupuesto_usado = sum(costo[m]*x[m].varValue for m in medios)
print("Presupuesto usado:", presupuesto_usado, "/ 10000")

Nota didáctica

Si el número de anuncios debe ser entero, se debe cambiar la definición de variables a cat="Integer". En esta sección se conserva el modelo como PL continua para mantener el enfoque lineal básico.

PL-SEC5-EJ06

Cartera básica de inversión

Planteamiento del problema

Un inversionista desea distribuir el 100% de su capital entre acciones, bonos y efectivo. Los retornos esperados son 12%, 7% y 3%, respectivamente. Los indicadores de riesgo son 20%, 8% y 1%. El riesgo promedio de la cartera no puede superar 10% y ningún activo puede representar más del 70% del portafolio. Se desea maximizar el retorno esperado.

ActivoRetorno esperadoRiesgoMáximo
Acciones0.120.200.70
Bonos0.070.080.70
Efectivo0.030.010.70

Modelo matemático

wi = proporción invertida en activo i
Maximizar R = ∑i ri wi
∑i wi = 1
∑i qi wi ≤ 0.10
0 ≤ wi ≤ 0.70 ∀ i

Código Python explicado línea por línea

# Importa PuLP.
import pulp as pl

# Define los activos disponibles.
activos = ["acciones", "bonos", "efectivo"]

# Define el retorno esperado de cada activo.
retorno = {"acciones": 0.12, "bonos": 0.07, "efectivo": 0.03}

# Define el riesgo asociado a cada activo.
riesgo = {"acciones": 0.20, "bonos": 0.08, "efectivo": 0.01}

# Crea un modelo de maximización del retorno esperado.
modelo = pl.LpProblem("cartera_inversion", pl.LpMaximize)

# Crea variables de proporción con límite inferior 0 y superior 0.70.
w = pl.LpVariable.dicts("peso", activos, lowBound=0, upBound=0.70)

# Define la función objetivo: retorno esperado total de la cartera.
modelo += pl.lpSum(retorno[a]*w[a] for a in activos), "Retorno_esperado"

# Agrega la restricción de inversión total: todos los pesos deben sumar 1.
modelo += pl.lpSum(w[a] for a in activos) == 1, "Presupuesto_total"

# Agrega la restricción de riesgo promedio máximo.
modelo += pl.lpSum(riesgo[a]*w[a] for a in activos) <= 0.10, "Riesgo_maximo"

# Resuelve el modelo.
estado = modelo.solve(pl.PULP_CBC_CMD(msg=False))

# Imprime estado y composición de cartera.
print("Estado:", pl.LpStatus[estado])
for a in activos:
    print(a, "=", w[a].varValue)

# Imprime retorno óptimo y riesgo utilizado.
print("Retorno esperado:", pl.value(modelo.objective))
print("Riesgo cartera:", sum(riesgo[a]*w[a].varValue for a in activos))
print("Suma pesos:", sum(w[a].varValue for a in activos))

Interpretación

El modelo distribuye el capital maximizando retorno sin exceder el riesgo permitido. La validación debe mostrar que los pesos suman exactamente 1 y que el riesgo promedio no supera 0.10.

PL-SEC5-EJ07

Planeación de turnos

Planteamiento del problema

Una operación requiere cubrir tres franjas: mañana, tarde y noche. Existen tres tipos de turnos. El turno T1 cubre mañana y tarde y cuesta 90 por trabajador. El turno T2 cubre tarde y noche y cuesta 100. El turno T3 cubre mañana y noche y cuesta 110. Se requieren al menos 8 trabajadores en la mañana, 10 en la tarde y 6 en la noche. Se desea minimizar el costo total de personal.

TurnoCostoMañanaTardeNoche
T190110
T2100011
T3110101
Demanda—8106

Modelo matemático

xt = número de trabajadores asignados al turno t
Minimizar C = 90xT1 + 100xT2 + 110xT3
xT1 + xT3 ≥ 8 (mañana)
xT1 + xT2 ≥ 10 (tarde)
xT2 + xT3 ≥ 6 (noche)
xt ≥ 0

Código Python explicado línea por línea

# Importa PuLP.
import pulp as pl

# Define los turnos disponibles.
turnos = ["T1", "T2", "T3"]

# Define las franjas de demanda.
franjas = ["manana", "tarde", "noche"]

# Define el costo por trabajador en cada turno.
costo = {"T1": 90, "T2": 100, "T3": 110}

# Define la demanda mínima por franja.
demanda = {"manana": 8, "tarde": 10, "noche": 6}

# Define si cada turno cubre o no cada franja.
cubre = {
    ("T1", "manana"): 1, ("T1", "tarde"): 1, ("T1", "noche"): 0,
    ("T2", "manana"): 0, ("T2", "tarde"): 1, ("T2", "noche"): 1,
    ("T3", "manana"): 1, ("T3", "tarde"): 0, ("T3", "noche"): 1
}

# Crea el modelo de minimización de costo laboral.
modelo = pl.LpProblem("planeacion_turnos", pl.LpMinimize)

# Crea variables no negativas para trabajadores asignados a cada turno.
x = pl.LpVariable.dicts("trabajadores", turnos, lowBound=0)

# Define la función objetivo como costo total de trabajadores asignados.
modelo += pl.lpSum(costo[t]*x[t] for t in turnos), "Costo_total"

# Agrega una restricción de cobertura mínima para cada franja.
for f in franjas:
    modelo += pl.lpSum(cubre[t, f]*x[t] for t in turnos) >= demanda[f], f"Cobertura_{f}"

# Resuelve el modelo.
estado = modelo.solve(pl.PULP_CBC_CMD(msg=False))

# Imprime estado y trabajadores por turno.
print("Estado:", pl.LpStatus[estado])
for t in turnos:
    print(t, "=", x[t].varValue)

# Imprime costo total mínimo.
print("Costo mínimo:", pl.value(modelo.objective))

# Valida cobertura por franja.
for f in franjas:
    cobertura = sum(cubre[t, f]*x[t].varValue for t in turnos)
    print("Cobertura", f, cobertura, "/", demanda[f])

Nota didáctica

Este modelo se presenta como PL continua. En un caso real, los trabajadores son indivisibles y convendría usar cat="Integer"; eso lo convierte en Programación Lineal Entera.

PL-SEC5-EJ08

Comparación PuLP vs scipy.optimize.linprog

Planteamiento del problema

Se resolverá el mismo problema de producción del ejemplo 1 con dos enfoques: PuLP y linprog. El objetivo es mostrar que PuLP permite una formulación más parecida al modelo matemático, mientras que linprog exige escribir matrices y vectores.

Modelo matemático

Maximizar Z = 40xA + 30xB
2xA + xB ≤ 100
xA + xB ≤ 80
xA, xB ≥ 0

Código con linprog explicado línea por línea

# Importa la función linprog desde scipy.optimize.
from scipy.optimize import linprog

# linprog resuelve problemas de minimización.
# Para maximizar 40x_A + 30x_B, minimizamos su negativo.
c = [-40, -30]

# Define la matriz A_ub de restricciones de tipo menor o igual.
A_ub = [
    [2, 1],  # Coeficientes de 2x_A + x_B <= 100.
    [1, 1]   # Coeficientes de x_A + x_B <= 80.
]

# Define el vector b_ub con los lados derechos de las restricciones.
b_ub = [100, 80]

# Define los límites de cada variable: ambas son no negativas y sin cota superior.
bounds = [(0, None), (0, None)]

# Resuelve el modelo usando el método HiGHS.
resultado = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method="highs")

# Imprime si la optimización fue exitosa.
print("Éxito:", resultado.success)

# Imprime el mensaje técnico del solver.
print("Mensaje:", resultado.message)

# Imprime los valores óptimos de x_A y x_B.
print("Variables:", resultado.x)

# Como se minimizó el negativo, el valor máximo original es -resultado.fun.
print("Valor objetivo máximo:", -resultado.fun)

Interpretación

El resultado debe coincidir con PuLP: x_A = 20, x_B = 60, Z = 2600. La diferencia principal está en la forma de implementar: PuLP es más declarativo y linprog es más matricial.

PL-SEC5-EJ09

Validación automática de soluciones

Planteamiento del problema

Después de resolver un modelo en Python, es buena práctica verificar automáticamente si la solución cumple las restricciones. Se usará nuevamente el problema de producción con dos productos para construir una función de validación que revise capacidad de máquina, ensamble y no negatividad.

Modelo matemático validado

2xA + xB ≤ 100
xA + xB ≤ 80
xA, xB ≥ 0

Código Python explicado línea por línea

# Define una función que recibe una solución candidata x_A, x_B.
def validar_solucion(x_A, x_B):

    # Define una tolerancia pequeña para evitar errores numéricos por redondeo.
    tolerancia = 1e-6

    # Calcula el lado izquierdo de la restricción de máquina.
    uso_maquina = 2*x_A + x_B

    # Calcula el lado izquierdo de la restricción de ensamble.
    uso_ensamble = x_A + x_B

    # Crea un diccionario con cada prueba lógica de factibilidad.
    chequeos = {
        "maquina": uso_maquina <= 100 + tolerancia,
        "ensamble": uso_ensamble <= 80 + tolerancia,
        "x_A_no_negativa": x_A >= -tolerancia,
        "x_B_no_negativa": x_B >= -tolerancia
    }

    # Devuelve el diccionario de chequeos junto con los usos calculados.
    return chequeos, uso_maquina, uso_ensamble

# Evalúa la solución óptima esperada.
chequeos, uso_maquina, uso_ensamble = validar_solucion(20, 60)

# Imprime el resultado de cada chequeo.
print(chequeos)

# Imprime los consumos calculados.
print("Uso máquina:", uso_maquina)
print("Uso ensamble:", uso_ensamble)

# Verifica si todos los chequeos son verdaderos.
print("Solución factible:", all(chequeos.values()))

Interpretación

La validación automática es clave cuando se generan muchos escenarios o cuando los resultados se exportan a reportes. Evita aceptar soluciones mal copiadas, mal redondeadas o interpretadas de forma incorrecta.

PL-SEC5-EJ10

Exportación de resultados a Excel

Planteamiento del problema

Una vez resuelto un modelo de Programación Lineal, normalmente se requiere comunicar los resultados. En este ejemplo se resuelve el modelo de producción y se exportan a Excel tres tablas: variables óptimas, uso de recursos y resumen del valor objetivo.

Modelo matemático

Maximizar Z = 40xA + 30xB
2xA + xB ≤ 100
xA + xB ≤ 80
xA, xB ≥ 0

Código Python explicado línea por línea

# Importa PuLP para resolver el modelo.
import pulp as pl

# Importa pandas para construir tablas y exportarlas a Excel.
import pandas as pd

# Crea el modelo de maximización.
modelo = pl.LpProblem("produccion_exportable", pl.LpMaximize)

# Crea las variables de decisión no negativas.
x_A = pl.LpVariable("Producto_A", lowBound=0)
x_B = pl.LpVariable("Producto_B", lowBound=0)

# Agrega la función objetivo.
modelo += 40*x_A + 30*x_B, "Utilidad_total"

# Agrega las restricciones de recursos.
modelo += 2*x_A + x_B <= 100, "Maquina"
modelo += x_A + x_B <= 80, "Ensamble"

# Resuelve el modelo.
estado = modelo.solve(pl.PULP_CBC_CMD(msg=False))

# Crea una tabla con los valores óptimos de las variables.
tabla_variables = pd.DataFrame({
    "Variable": ["Producto_A", "Producto_B"],
    "Valor óptimo": [x_A.varValue, x_B.varValue]
})

# Calcula el uso de cada recurso.
uso_maquina = 2*x_A.varValue + x_B.varValue
uso_ensamble = x_A.varValue + x_B.varValue

# Crea una tabla con uso, disponibilidad y holgura de recursos.
tabla_recursos = pd.DataFrame({
    "Recurso": ["Maquina", "Ensamble"],
    "Uso": [uso_maquina, uso_ensamble],
    "Disponible": [100, 80],
    "Holgura": [100 - uso_maquina, 80 - uso_ensamble]
})

# Crea una tabla resumen con estado y valor objetivo.
tabla_resumen = pd.DataFrame({
    "Indicador": ["Estado", "Utilidad máxima"],
    "Valor": [pl.LpStatus[estado], pl.value(modelo.objective)]
})

# Abre un escritor de Excel para crear un archivo con varias hojas.
with pd.ExcelWriter("resultados_programacion_lineal.xlsx") as writer:

    # Exporta la tabla de variables a la hoja Variables.
    tabla_variables.to_excel(writer, index=False, sheet_name="Variables")

    # Exporta la tabla de recursos a la hoja Recursos.
    tabla_recursos.to_excel(writer, index=False, sheet_name="Recursos")

    # Exporta la tabla resumen a la hoja Resumen.
    tabla_resumen.to_excel(writer, index=False, sheet_name="Resumen")

# Informa que el archivo fue creado.
print("Archivo resultados_programacion_lineal.xlsx generado correctamente.")

Interpretación

El archivo de Excel permite revisar la solución en un formato familiar para gerentes, docentes o estudiantes. Además, conserva trazabilidad entre variables, recursos y valor objetivo.
