A5. Resolución con Python

A1 FormulaciónA2 GráficoA3 SimplexA4 SolverA5 PythonA6 Sensibilidad

Competencia: Implementar y validar modelos de PL con PuLP, usando scipy.optimize.linprog como alternativa.

Guía de aprendizaje

  • Instalar y cargar librerías.
  • Traducir el modelo matemático a objetos de Python.
  • Usar nombres claros para variables y restricciones.
  • Resolver e interpretar estado del solver.
  • Validar factibilidad y valor objetivo.
  • Automatizar escenarios y exportar resultados.

Buenas prácticas y errores comunes

  • No programar antes de formular el modelo matemático.
  • Revisar el sentido: LpMaximize vs LpMinimize.
  • En linprog, recordar que por defecto minimiza.
  • Validar resultados con cálculos manuales o Solver en ejemplos pequeños.

Producción básica con PuLP

Planteamiento

Implementación en Python de un problema de PL: Maximización con dos productos y dos recursos.

Datos

ComponenteRecomendación
Librería principalPuLP
Alternativascipy.optimize.linprog
ValidaciónRecalcular restricciones con la solución
Resultado esperadox1=20, x2=60, Z=2600

Variables de decisión

Crear objetos LpVariable con lowBound=0. Para problemas indexados, usar diccionarios de variables.

Función objetivo

En PuLP se agrega con modelo += expresión, "nombre_objetivo".

Restricciones

Cada restricción se agrega como una expresión lineal con <=, >= o == y un nombre claro.

Dominio

Por defecto se modelan variables continuas no negativas. Para enteras: cat="Integer"; para binarias: cat="Binary".

Método / procedimiento

  • Escribir primero el modelo matemático.
  • Crear el problema con LpMaximize o LpMinimize.
  • Definir variables.
  • Agregar objetivo y restricciones.
  • Resolver.
  • Imprimir estado, variables, objetivo y holguras.
  • Validar factibilidad recalculando los lados izquierdos.

Solución

Solución esperada: x1=20, x2=60, Z=2600.

Interpretación

Python permite reproducibilidad, automatización y comparación de escenarios. La salida debe traducirse a una recomendación operativa.

Verificación

El estado debe ser Optimal. Si aparece Infeasible o Unbounded, revisar datos, signos de restricciones y unidades.

Código / configuración

import pulp as pl

modelo = pl.LpProblem("modelo_PL", pl.LpMaximize)  # usar LpMinimize si aplica
x1 = pl.LpVariable("x1", lowBound=0)
x2 = pl.LpVariable("x2", lowBound=0)

modelo += 40*x1 + 30*x2, "Funcion_objetivo"
modelo += 2*x1 + x2 <= 100, "Recurso_1"
modelo += x1 + x2 <= 80, "Recurso_2"

modelo.solve(pl.PULP_CBC_CMD(msg=False))
print(pl.LpStatus[modelo.status])
print(x1.varValue, x2.varValue, pl.value(modelo.objective))
