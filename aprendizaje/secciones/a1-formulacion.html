A1. Formulación de modelos de Programación Lineal

A1 FormulaciónA2 GráficoA3 SimplexA4 SolverA5 PythonA6 Sensibilidad

Competencia: Traducir problemas reales a modelos matemáticos lineales completos y verificables.

Guía de aprendizaje

  • Leer el contexto y separar decisiones, datos, restricciones y objetivo.
  • Definir variables con nombre, unidad y periodo de tiempo.
  • Construir una función objetivo económica o técnica.
  • Expresar restricciones con unidades consistentes.
  • Agregar dominio: no negatividad, continuidad o integralidad si aplica.
  • Validar que cada dato del enunciado aparezca en el modelo o esté justificado.

Buenas prácticas y errores comunes

  • No mezclar unidades: horas por unidad con horas totales, dinero por unidad con dinero total.
  • Evitar variables ambiguas como x sin explicar qué representa.
  • No convertir porcentajes sin revisar si están en fracción o porcentaje.
  • Distinguir restricciones de capacidad (<=), requerimientos mínimos (>=) y balances (=).

PL-SEC1-EJ01

Producción de mesas y sillas

Planteamiento

Una carpintería universitaria produce mesas de estudio y sillas. Debe decidir cuántas unidades fabricar durante una semana para maximizar utilidad sin exceder horas de carpintería, pintura y empaque.

Datos

ProductoUtilidadCarpintería h/uPintura h/uEmpaque h/uDemanda máxima
Mesa5042118
Silla30210.530
Disponibilidad—804016—

Variables de decisión

x1 = mesas a producir por semana; x2 = sillas a producir por semana.

Función objetivo

Max Z = 50x1 + 30x2

Restricciones

4x1 + 2x2 <= 80 carpintería
2x1 + x2 <= 40 pintura
x1 + 0.5x2 <= 16 empaque
x1 <= 18 demanda máxima de mesas
x2 <= 30 demanda máxima de sillas

Dominio

x1, x2 >= 0. Si solo se aceptan unidades completas, agregar x1, x2 enteras; como PL continua se permite solución fraccionaria.

Método / procedimiento

Se formula como PL de maximización con recursos limitados. Al resolver gráficamente o con Solver, el empaque limita la producción.

Solución

Una solución óptima continua es x1 = 2 mesas, x2 = 28 sillas, Z = 940. Uso de recursos: carpintería 64 h, pintura 32 h, empaque 16 h.

Interpretación

Conviene producir principalmente sillas porque consumen menos empaque por unidad de utilidad en este conjunto de datos. El recurso crítico es empaque.

Verificación

La solución cumple todas las disponibilidades y demandas. La unidad de cada restricción son horas disponibles por semana.

PL-SEC1-EJ02

Mezcla de alimentos balanceados

Planteamiento

Una planta prepara alimento para aves mezclando maíz, soya y afrecho. El objetivo es minimizar el costo por tonelada cumpliendo mínimos nutricionales.

Datos

IngredienteCosto USD/tProteína %Fibra %Energía kcal/kg
Maíz240823300
Soya4204472800
Afrecho18015121800
Requerimiento—>=18<=6>=2600

Variables de decisión

x1, x2, x3 = toneladas de maíz, soya y afrecho en una tonelada de mezcla.

Función objetivo

Min C = 240x1 + 420x2 + 180x3

Restricciones

x1 + x2 + x3 = 1
0.08x1 + 0.44x2 + 0.15x3 >= 0.18
0.02x1 + 0.07x2 + 0.12x3 <= 0.06

Interpretación

La mezcla usa afrecho por su bajo costo, pero limita su participación por fibra y energía.

Verificación

La suma de proporciones es 1 y todos los nutrientes cumplen los rangos.

Dieta mínima para cafetería

Planteamiento

Una cafetería institucional debe diseñar una ración económica usando arroz, pollo y fríjol que cumpla requerimientos de proteína y calorías.

Datos

AlimentoCosto por porciónProteína gCalorías
Arroz0.404200
Pollo1.2025180
Fríjol0.7012150
Requerimiento—>=35>=700

Variables de decisión

x1 = porciones de arroz; x2 = porciones de pollo; x3 = porciones de fríjol.

Función objetivo

Min C = 0.40x1 + 1.20x2 + 0.70x3

Restricciones

4x1 + 25x2 + 12x3 >= 35
200x1 + 180x2 + 150x3 >= 700
x2 <= 2 límite operativo de pollo

Dominio

x1, x2, x3 >= 0.

Modelo de dieta de minimización. Las restricciones son mínimos nutricionales y límites operativos.

PL-SEC1-EJ04

Transporte simple desde plantas a mercados

Planteamiento

Dos plantas despachan producto a tres ciudades. Se busca minimizar el costo de transporte semanal cumpliendo demandas y respetando capacidades.

Datos

Origen/DestinoCiudad 1Ciudad 2Ciudad 3Oferta
Planta A6810120
Planta B759100
Demanda809050220

Variables de decisión

xij = unidades enviadas desde planta i hacia ciudad j.

Función objetivo

Min C = 6xA1 + 8xA2 + 10xA3 + 7xB1 + 5xB2 + 9xB3

Restricciones

xA1+xA2+xA3 <= 120
xB1+xB2+xB3 <= 100
xA1+xB1 = 80
xA2+xB2 = 90
xA3+xB3 = 50

Dominio

xij >= 0.

Método / procedimiento

Modelo clásico de transporte balanceado: oferta total igual a demanda total.

Solución

Una solución óptima por costos relativos: A->C1 = 80, A->C3 = 40, B->C2 = 90, B->C3 = 10. Costo = 80*6 + 40*10 + 90*5 + 10*9 = 1420.

Interpretación

La planta B abastece preferentemente Ciudad 2 por su bajo costo unitario; Planta A abastece Ciudad 1.

Verificación

Planta A envía 120, Planta B envía 100; demandas: C1=80, C2=90, C3=50.

PL-SEC1-EJ05

Asignación simple de tareas

Planteamiento

Tres analistas deben asignarse a tres tareas. Cada analista puede ejecutar una tarea y cada tarea requiere un analista. Se minimiza el tiempo total.

Datos

Analista/TareaT1T2T3
A1869
A2758
A3674

Variables de decisión

xij = 1 si el analista i se asigna a la tarea j; 0 en caso contrario.

Función objetivo

Min T = 8x11+6x12+9x13+7x21+5x22+8x23+6x31+7x32+4x33

Restricciones

Para cada analista: suma de sus asignaciones = 1
Para cada tarea: suma de analistas asignados = 1

Dominio

xij >= 0 en relajación lineal; en asignación exacta xij binaria. La matriz totalmente unimodular permite solución entera en la relajación.

Modelo de asignación. Aunque usa variables binarias, se presenta como extensión natural de PL.

Todas las filas y columnas suman 1.

Planteamiento

Una empresa minorista decide cuántos anuncios comprar en radio, prensa digital y redes para maximizar impactos ponderados con presupuesto y límites de frecuencia.

Datos

Variables de decisión

Función objetivo

Max I = 4200x1 + 2600x2 + 1800x3

Restricciones

500x1 + 350x2 + 200x3 <= 6000

x2 <= 10

PL-SEC1-EJ07

Cartera básica de inversión

Planteamiento

Un fondo universitario invierte en bonos, acciones y CDT. Busca maximizar retorno anual esperado con límites de riesgo y diversificación.

Datos

ActivoRetorno esperadoRiesgo índiceMáximo
Bonos7%260%
Acciones13%845%
CDT5%150%
Límite riesgo promedio—<=4—

Variables de decisión

x1, x2, x3 = proporción del capital invertida en bonos, acciones y CDT.

Función objetivo

Max R = 0.07x1 + 0.13x2 + 0.05x3

Restricciones

x1 + x2 + x3 = 1
2x1 + 8x2 + 1x3 <= 4
x1 <= 0.60
x2 <= 0.45
x3 <= 0.50

Dominio

x1, x2, x3 >= 0.

Método / procedimiento

Modelo de cartera lineal simplificada con riesgo promedio ponderado.

Solución

Para maximizar retorno se usa el máximo posible en acciones bajo riesgo. Con x1=0.60, x2=0.3333, x3=0.0667 se obtiene riesgo = 4.0 y retorno aproximado = 9.0%.

Interpretación

La cartera usa muchas acciones por retorno alto, pero el límite de riesgo exige bonos y una pequeña proporción de CDT.

Verificación

Suma=0.60+0.3333+0.0667=1. Riesgo=2(0.60)+8(0.3333)+1(0.0667)=3.933 aproximadamente por redondeo; usando x2=1/3 exacto, x3=1/15, el riesgo se mantiene dentro del límite.

PL-SEC1-EJ10

Localización simplificada de centros

Planteamiento

Una empresa evalúa operar dos microcentros para atender demanda en tres zonas. Como aproximación lineal, decide flujo desde cada centro abierto con capacidades máximas dadas.

Datos

Centro/ZonaZ1Z2Z3Capacidad
C1469100
C254790
Demanda607040170

Variables de decisión

xij = unidades enviadas desde centro i a zona j.

Función objetivo

Min C = 4x11+6x12+9x13+5x21+4x22+7x23

Restricciones

x11+x12+x13 <= 100
x21+x22+x23 <= 90
x11+x21 = 60
x12+x22 = 70
x13+x23 = 40

Dominio

xij >= 0.

Método / procedimiento

Modelo de localización-distribución simplificado sin costos fijos. Si se agregan aperturas, se convierte en entero mixto.

Solución

Óptimo por costos: C1->Z1=60, C1->Z3=40, C2->Z2=70. Costo=60*4+40*9+70*4=880.

Interpretación

C1 atiende Z1 y Z3; C2 atiende Z2 por menor costo.

Verificación

Capacidad C1=100, C2=70<=90; demandas cubiertas.
