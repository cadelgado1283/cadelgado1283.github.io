A1. Formulación de modelos de Programación Lineal

A1 Formulación A2 Gráfico A3 Simplex A4 Solver A5 Python A6 Sensibilidad

Competencia: traducir problemas reales de decisión a modelos matemáticos lineales completos, coherentes y verificables, identificando variables de decisión, parámetros, función objetivo, restricciones, dominio, unidades y supuestos.

¿Qué significa formular un modelo de Programación Lineal?

Formular un modelo de Programación Lineal consiste en convertir una situación real de decisión en un sistema matemático compuesto por una función objetivo lineal, restricciones lineales y condiciones de dominio. La formulación es la etapa más importante del proceso de optimización: si el modelo representa mal el problema, ningún método de solución —gráfico, simplex, Solver o Python— podrá entregar una recomendación confiable.

Un modelo de PL responde tres preguntas fundamentales:

¿Qué se decide?
Las variables de decisión representan las cantidades que el decisor puede controlar.
¿Qué se quiere lograr?
La función objetivo mide utilidad, costo, ingreso, desperdicio, cobertura, riesgo o tiempo.
¿Qué limita la decisión?
Las restricciones representan capacidades, demandas, balances, políticas, presupuestos o requerimientos mínimos.

Teoría esencial de la formulación de modelos

1. Estructura general de un modelo de PL

Una forma general de un modelo lineal de maximización es:

Modelo general de maximización
Maximizar Z = c1x1 + c2x2 + … + cnxn
sujeto a
a11x1 + a12x2 + … + a1nxn ≤ b1
a21x1 + a22x2 + … + a2nxn ≤ b2
⋮
xj ≥ 0, para todo j = 1, …, n

En un problema de minimización se reemplaza “Maximizar” por “Minimizar”. Las restricciones pueden ser de tipo ≤, ≥ o =, según el significado del problema.

2. Variables de decisión

Las variables de decisión son las incógnitas que el modelo debe determinar. No son datos del problema: son decisiones. Una variable bien definida debe incluir nombre, unidad, alcance y periodo de tiempo.

Ejemplo correcto: x1 = número de mesas producidas por semana.
Ejemplo débil: x = mesas.

3. Parámetros

Los parámetros son datos conocidos: costos unitarios, consumos de recurso, disponibilidades, demandas, rendimientos, precios, límites de presupuesto o requerimientos mínimos. Deben tratarse como constantes.

4. Función objetivo

La función objetivo traduce el criterio de decisión. Si se desea maximizar utilidad, cada variable debe multiplicarse por la utilidad unitaria. Si se desea minimizar costo, cada variable debe multiplicarse por su costo unitario.

Maximizar utilidad: Z = Σ utilidad unitaria × cantidad decidida
Minimizar costo: C = Σ costo unitario × cantidad decidida

5. Restricciones

Las restricciones son las reglas que limitan o exigen ciertos valores. Cada restricción debe leerse como una frase lógica:

  • Capacidad: consumo total ≤ disponibilidad.
  • Demanda mínima: producción o cobertura total ≥ requerimiento.
  • Balance: entradas − salidas = cambio de inventario.
  • Proporción: parte de la mezcla respecto al total cumple un porcentaje.
  • Asignación: cada tarea se asigna exactamente una vez.
  • Presupuesto: gasto total ≤ presupuesto disponible.

6. Dominio

El dominio indica qué valores puede tomar cada variable. En PL continua, lo usual es xj ≥ 0. Cuando se requieren unidades indivisibles, se habla de programación lineal entera o mixta; aun así, la formulación lineal básica sirve como punto de partida.

7. Linealidad

Un modelo es lineal cuando las variables aparecen solo multiplicadas por constantes y no hay productos entre variables, potencias, raíces, cocientes con variables ni funciones no lineales.

Lineal:
3x1 + 2x2 ≤ 100
No lineal:
x1x2 ≤ 100, x12 ≤ 50

Guía de aprendizaje paso a paso

  1. Leer el contexto completo. Antes de escribir ecuaciones, identifica qué organización, proceso o sistema se está modelando. Pregunta: ¿producción, mezcla, transporte, dieta, inversión, turnos o asignación?
  2. Separar datos de decisiones. Los datos son números conocidos; las decisiones son cantidades por determinar. Una forma útil es subrayar verbos como producir, enviar, comprar, invertir, asignar, contratar o mezclar.
  3. Definir variables con precisión. Escribe cada variable con unidad y periodo. Evita variables ambiguas. Si hay muchos índices, define conjuntos: plantas, mercados, alimentos, activos, turnos o tareas.
  4. Elegir el criterio de optimización. Decide si la función objetivo maximiza o minimiza. Verifica que todos sus términos estén en la misma unidad: dinero, horas, toneladas, impactos, riesgo o desperdicio.
  5. Construir la función objetivo. Multiplica cada variable por su contribución unitaria. Si una variable representa proporción, el coeficiente debe interpretarse como contribución por unidad de proporción del total.
  6. Formular restricciones de recursos. Para cada recurso limitado, calcula consumo total y compáralo con disponibilidad. Estructura típica: Σ consumo unitario × cantidad ≤ disponibilidad.
  7. Formular restricciones de requerimiento. Si se debe cumplir una meta mínima, usa ≥. Ejemplos: proteína mínima, demanda mínima, cobertura mínima o inversión mínima.
  8. Formular restricciones de balance. En transporte e inventarios, los balances son esenciales. Una demanda debe cubrirse exactamente o al menos, según el caso.
  9. Agregar dominio y supuestos. Incluye no negatividad, continuidad o integralidad. Declara supuestos como divisibilidad, certidumbre de datos, linealidad y horizonte de planeación.
  10. Validar el modelo. Revisa que cada dato importante del enunciado aparezca en alguna ecuación o esté justificado. Verifica unidades, signos, sentido de desigualdades y consistencia del resultado.

Buenas prácticas y errores comunes explicados

Buena práctica 1: nombrar variables con significado.
Una variable debe ser entendible sin mirar la ecuación. Use xA para producto A o xij para flujo desde origen i hacia destino j.
Buena práctica 2: cuidar unidades.
Si el lado izquierdo está en horas, el lado derecho también debe estar en horas. Si la FO está en pesos, cada término debe representar pesos.
Buena práctica 3: distinguir datos y variables.
La demanda, el costo y la disponibilidad suelen ser parámetros; la producción, envío o inversión suele ser decisión.
Buena práctica 4: usar índices.
En transporte, asignación y dietas con muchos elementos, los índices evitan escribir modelos desordenados y facilitan codificación en Solver o Python.
Error común 1: invertir el signo.
Una capacidad se modela normalmente como ≤; un requerimiento mínimo como ≥; un balance exacto como =.
Error común 2: olvidar no negatividad.
Sin x ≥ 0, el modelo podría recomendar producir, enviar o comprar cantidades negativas.
Error común 3: modelar porcentajes mal.
Un 18% debe escribirse como 0.18 si se trabaja en proporciones. En mezclas, el nutriente ponderado suele ser Σ contenido × proporción.
Error común 4: confundir solución con formulación.
Formular no es resolver. Primero se construye el modelo; luego se usa gráfico, simplex, Solver o Python para obtener valores óptimos.

PL-SEC1-EJ01

Producción de mesas y sillas

Planteamiento. Una carpintería universitaria fabrica mesas de estudio y sillas. Durante una semana dispone de tres recursos: carpintería, pintura y empaque. El gerente debe decidir cuántas mesas y cuántas sillas fabricar para maximizar la utilidad semanal. Además, el área comercial estima que no se venderán más de 18 mesas ni más de 30 sillas durante la semana.

ProductoUtilidadCarpintería h/uPintura h/uEmpaque h/uDemanda máxima
Mesa5042118
Silla30210.530
Disponibilidad—804016—

Paso 1. Variables

x1 = mesas producidas por semana; x2 = sillas producidas por semana.

Paso 2. Modelo matemático

Modelo de producción
Maximizar Z = 50x1 + 30x2
sujeto a
4x1 + 2x2 ≤ 80 carpintería
2x1 + x2 ≤ 40 pintura
x1 + 0.5x2 ≤ 16 empaque
x1 ≤ 18,   x2 ≤ 30 demanda máxima
x1, x2 ≥ 0

Paso 3. Resolución e interpretación

Al comparar recursos se observa que empaque es más restrictivo: x1 + 0.5x2 ≤ 16. Dado que una silla genera más utilidad por hora de empaque que una mesa, conviene llevar sillas hasta su demanda máxima y usar el empaque restante en mesas.

Si x2 = 30, entonces x1 + 0.5(30) ≤ 16 ⇒ x1 ≤ 1
Solución: x1 = 1, x2 = 30
Z = 50(1) + 30(30) = 950

Verificación

Carpintería: 4(1)+2(30)=64≤80. Pintura: 2(1)+30=32≤40. Empaque: 1+0.5(30)=16. La restricción activa es empaque.

PL-SEC1-EJ02

Mezcla de alimentos balanceados

Planteamiento. Una planta de alimentos para aves debe preparar una tonelada de alimento balanceado usando maíz, soya y afrecho. La mezcla debe cumplir un mínimo de proteína, un máximo de fibra y un mínimo de energía. El objetivo es minimizar el costo por tonelada.

IngredienteCosto USD/tProteínaFibraEnergía kcal/kg
Maíz2408%2%3300
Soya42044%7%2800
Afrecho18015%12%1800
Requerimiento—≥18%≤6%≥2600

Variables y modelo

x1, x2, x3 = toneladas de maíz, soya y afrecho dentro de una tonelada de mezcla.

Modelo de mezcla
Minimizar C = 240x1 + 420x2 + 180x3
x1 + x2 + x3 = 1
0.08x1 + 0.44x2 + 0.15x3 ≥ 0.18
0.02x1 + 0.07x2 + 0.12x3 ≤ 0.06
3300x1 + 2800x2 + 1800x3 ≥ 2600
x1, x2, x3 ≥ 0

Resolución paso a paso

  1. La primera restricción garantiza que la mezcla sea exactamente una tonelada.
  2. Las restricciones nutricionales son promedios ponderados de cada ingrediente.
  3. Al resolver el sistema lineal con las restricciones activas de proteína, fibra y suma, se obtiene una mezcla económica que respeta energía.
x1 = 0.4892,   x2 = 0.2215,   x3 = 0.2892
C = 262.52 USD/t

Interpretación y verificación

La mezcla usa soya para elevar proteína, maíz para energía y afrecho por bajo costo, limitado por la fibra. Proteína = 18%, fibra = 6% y energía ≈ 2670.8 kcal/kg.

PL-SEC1-EJ03

Dieta mínima para cafetería

Planteamiento. Una cafetería institucional desea diseñar una ración diaria de bajo costo usando arroz, pollo y fríjol. La ración debe aportar al menos 35 gramos de proteína y 700 calorías. Por disponibilidad de cocina, no se pueden usar más de 2 porciones de pollo.

AlimentoCosto por porciónProteína gCalorías
Arroz0.404200
Pollo1.2025180
Fríjol0.7012150

Variables y modelo

x1 = porciones de arroz; x2 = porciones de pollo; x3 = porciones de fríjol.

Modelo de dieta
Minimizar C = 0.40x1 + 1.20x2 + 0.70x3
4x1 + 25x2 + 12x3 ≥ 35 proteína
200x1 + 180x2 + 150x3 ≥ 700 calorías
x2 ≤ 2
x1, x2, x3 ≥ 0

Resolución paso a paso

  1. El arroz aporta calorías baratas, pero poca proteína.
  2. El pollo aporta mucha proteína, pero es más costoso.
  3. El óptimo continuo equilibra arroz y pollo; el fríjol no entra porque, con estos datos, no mejora el costo frente a la combinación arroz-pollo.
x1 = 2.6168,   x2 = 0.9813,   x3 = 0
C = 2.2243

Verificación

Proteína: 4(2.6168)+25(0.9813)=35. Calorías: 200(2.6168)+180(0.9813)=700. Ambas restricciones nutricionales quedan activas.

PL-SEC1-EJ04

Transporte simple desde plantas a mercados

Planteamiento. Una empresa despacha un producto desde dos plantas hacia tres ciudades. Cada planta tiene una capacidad semanal y cada ciudad tiene una demanda que debe cubrirse exactamente. El objetivo es minimizar el costo total de transporte.

Origen/DestinoCiudad 1Ciudad 2Ciudad 3Oferta
Planta A6810120
Planta B759100
Demanda809050220

Variables y modelo

xij = unidades enviadas desde planta i hacia ciudad j.

Minimizar C = 6xA1 + 8xA2 + 10xA3 + 7xB1 + 5xB2 + 9xB3
xA1 + xA2 + xA3 ≤ 120
xB1 + xB2 + xB3 ≤ 100
xA1 + xB1 = 80
xA2 + xB2 = 90
xA3 + xB3 = 50
xij ≥ 0

Resolución

Ciudad 2 debe abastecerse preferentemente desde B por su bajo costo. Ciudad 1 es más barata desde A. La demanda restante de Ciudad 3 se reparte respetando las capacidades.

xA1=80, xA2=0, xA3=40, xB1=0, xB2=90, xB3=10
C = 80(6)+40(10)+90(5)+10(9)=1420

Verificación

Planta A envía 120 y Planta B envía 100. Todas las demandas se satisfacen exactamente.

Planteamiento. Una firma consultora debe asignar tres analistas a tres tareas. Cada analista puede realizar una sola tarea y cada tarea debe quedar asignada exactamente a un analista. El objetivo es minimizar el tiempo total estimado.

Variables y modelo

xij=1 si el analista i se asigna a la tarea j; 0 en caso contrario.

Minimizar T = 8x11+6x12+9x13+7x21+5x22+8x23+6x31+7x32+4x33

Modelo

x1 = anuncios en radio; x2 = anuncios en prensa; x3 = anuncios en redes.

Maximizar I = 4200x1 + 2600x2 + 1800x3

PL-SEC1-EJ07

Cartera básica de inversión

Planteamiento. Un fondo universitario debe distribuir su capital entre bonos, acciones y CDT. Se busca maximizar el retorno esperado, pero el riesgo promedio no puede superar 4 unidades. Además, se establecen límites máximos por instrumento para diversificar.

ActivoRetorno esperadoRiesgoMáximo
Bonos7%260%
Acciones13%845%
CDT5%150%

Modelo

x1, x2, x3 = proporción invertida en bonos, acciones y CDT.

Maximizar R = 0.07x1 + 0.13x2 + 0.05x3
x1 + x2 + x3 = 1
2x1 + 8x2 + x3 ≤ 4
x1 ≤ 0.60,   x2 ≤ 0.45,   x3 ≤ 0.50
x1, x2, x3 ≥ 0

Resolución

Las acciones tienen mayor retorno, pero también mayor riesgo. Se invierte lo máximo posible en bonos de retorno intermedio y bajo riesgo, y se incrementan acciones hasta alcanzar el límite de riesgo.

x1=0.6000, x2=0.3429, x3=0.0571
R = 8.9429% anual esperado
Riesgo = 2(0.60)+8(0.3429)+0.0571 = 4
PL-SEC1-EJ08

Corte de rollos simplificado

Planteamiento. Una empresa corta rollos de 100 cm para obtener piezas de 45 cm y 30 cm. Se han definido tres patrones de corte factibles. El objetivo es satisfacer la demanda usando el menor número de rollos.

PatrónPiezas 45 cmPiezas 30 cmDesperdicio
P12010
P21125
P30310
Demanda4060—

Modelo

x1, x2, x3 = número de rollos cortados con los patrones P1, P2 y P3.

Minimizar N = x1 + x2 + x3
2x1 + x2 ≥ 40
x2 + 3x3 ≥ 60
x1, x2, x3 ≥ 0

Resolución

El patrón P2 produce una pieza de cada tipo, pero genera más desperdicio. P1 y P3 satisfacen exactamente las demandas con bajo desperdicio.

x1=20, x2=0, x3=20
N=40 rollos

En la práctica, las variables deben ser enteras porque no se puede cortar una fracción de rollo.

PL-SEC1-EJ09

Planeación de turnos simplificada

Planteamiento. Un centro de atención opera en cuatro franjas: mañana, mediodía, tarde y noche. Cada operador asignado a un tipo de turno cubre dos franjas consecutivas. Se desea cubrir la demanda mínima de cada franja con el menor número de operadores.

TurnoCubre
T1Mañana y mediodía
T2Mediodía y tarde
T3Tarde y noche
T4Noche y mañana
DemandaM=8, D=12, T=10, N=6

Modelo

xk = operadores asignados al turno k.

Minimizar W = x1 + x2 + x3 + x4
x1 + x4 ≥ 8 mañana
x1 + x2 ≥ 12 mediodía
x2 + x3 ≥ 10 tarde
x3 + x4 ≥ 6 noche
x1, x2, x3, x4 ≥ 0

Resolución

Una solución óptima continua e implementable es:

x1=2, x2=10, x3=0, x4=6
W=18 operadores

Localización simplificada de centros

Planteamiento. Una empresa evalúa la operación de dos microcentros de distribución ya disponibles para atender tres zonas urbanas. En esta versión simplificada no se consideran costos fijos de apertura; solo se decide cuánto enviar desde cada centro hacia cada zona para minimizar el costo de distribución.

Cierre de la sección

La formulación es una habilidad central de Investigación de Operaciones. Antes de resolver cualquier modelo, verifica que la estructura matemática represente con fidelidad la situación real. Un buen modelo debe ser claro, trazable, dimensionalmente consistente, lineal, verificable y defendible ante un decisor.
