A6. Análisis de sensibilidad en Solver y Python

A1 FormulaciónA2 GráficoA3 SimplexA4 SolverA5 PythonA6 Sensibilidad

Competencia: Interpretar precios sombra, costos reducidos y rangos para tomar decisiones gerenciales bajo cambios marginales.

Guía de aprendizaje

  • Diferenciar sensibilidad de variables y restricciones.
  • Interpretar precio sombra solo dentro del rango permitido.
  • Leer costos reducidos para variables no básicas.
  • Distinguir restricciones activas y no activas.
  • Comparar reporte de Solver con salidas duales en Python cuando estén disponibles.
  • Resolver nuevamente si el cambio excede los rangos.

Buenas prácticas y errores comunes

  • No aplicar precios sombra fuera del rango de factibilidad.
  • No interpretar costos reducidos como pérdidas reales.
  • Cuidado con degeneración y óptimos alternativos.
  • En modelos enteros, el reporte clásico de sensibilidad no aplica igual.

PL-SEC6-EJ01

Precio sombra de capacidad

Planteamiento

Caso de interpretación de sensibilidad: Restricción de horas de máquina activa con precio sombra 12.

Datos

IndicadorValor de referencia
SituaciónRestricción de horas de máquina activa con precio sombra 12
Conclusión centralUna hora adicional aumenta Z en 12 dentro del rango

Variables de decisión

Variables de decisión del modelo óptimo original; las variables no básicas son aquellas con valor cero en la solución.

Función objetivo

La sensibilidad analiza cambios marginales en coeficientes de la función objetivo c o en lados derechos b, manteniendo la estructura lineal.

Restricciones

Se interpretan restricciones activas, holguras, precios sombra y rangos permitidos.

Dominio

El análisis es válido para el modelo lineal continuo y dentro de los rangos reportados.

Método / procedimiento

  • Identificar solución óptima base.
  • Determinar restricciones activas y no activas.
  • Leer precio sombra y rango de factibilidad para RHS.
  • Leer costo reducido y rango de optimalidad para coeficientes.
  • Traducir el resultado a una decisión gerencial.
  • Si el cambio está fuera del rango, resolver nuevamente el modelo.

Solución

Conclusión: Una hora adicional aumenta Z en 12 dentro del rango.

Interpretación

La sensibilidad no reemplaza resolver escenarios grandes. Sirve para cambios marginales y decisiones rápidas dentro de intervalos válidos.

Verificación

Confirmar que el cambio propuesto permanece dentro del rango permitido; si no, correr nuevamente Solver o Python.
