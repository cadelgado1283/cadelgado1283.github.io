A3. Método Simplex manual / tabular

A1 Formulación A2 Gráfico A3 Simplex A4 Solver A5 Python A6 Sensibilidad

Competencia: Aplicar el método simplex en su versión manual/tabular para resolver e interpretar modelos de Programación Lineal, incluyendo forma estándar, variables de holgura/exceso/artificiales, criterio de optimalidad, pivoteo, M grande, dos fases y casos especiales.

¿Qué es el método simplex y por qué es importante?

El método simplex es el algoritmo clásico para resolver problemas de Programación Lineal cuando el número de variables o restricciones hace impráctico el método gráfico. Su idea central es recorrer sistemáticamente los vértices de la región factible hasta encontrar uno que optimice la función objetivo. En su versión manual / tabular, cada iteración se organiza en una tabla que muestra la base actual, los coeficientes tecnológicos, la contribución de las variables básicas, los costos reducidos y el valor del lado derecho.

Pedagógicamente, el simplex permite entender:

  • cómo se construye una base factible inicial;
  • cómo se mueve el algoritmo de una solución básica factible a otra;
  • qué significa que una variable entre o salga de la base;
  • cómo detectar óptimo, degeneración, óptimos alternativos, infactibilidad y no acotación;
  • por qué las variables de holgura, exceso y artificiales son herramientas algebraicas fundamentales.
Intuición central: el simplex no “prueba al azar”. En cada iteración mejora la solución actual usando la información contenida en la fila de costos reducidos. Esa fila indica qué variable conviene introducir en la base para mejorar el valor de la función objetivo.

Fundamentos teóricos del método simplex

1. Forma estándar

Para trabajar tabularmente, el modelo se transforma a una forma algebraica manejable:

  • restricciones \le: se agrega una variable de holgura;
  • restricciones \ge: se resta una variable de exceso y normalmente se agrega una artificial;
  • restricciones de igualdad: suelen requerir una variable artificial si no existe una columna identidad natural;
  • todas las variables deben ser no negativas.

2. Base y solución básica factible

Una base es un conjunto de variables cuyas columnas forman una matriz identidad. En una tabla simplex, las variables básicas toman los valores del lado derecho (RHS) y las no básicas se fijan temporalmente en cero. Si todos los RHS son no negativos, se tiene una solución básica factible.

3. Estructura de la tabla simplex

La tabla simplex suele mostrar:

  • la columna Base y el costo básico Cb;
  • los coeficientes de cada variable en las restricciones;
  • el lado derecho RHS;
  • la fila Zj o Cj - Zj (también se usa Zj - Cj según convención).

En este material se usa principalmente la convención Cj − Zj para problemas de maximización: mientras exista un valor positivo en esa fila, aún puede mejorarse la función objetivo.

4. Regla de entrada y salida

  • Variable entrante: la variable no básica con mayor mejora potencial, usualmente el mayor valor positivo en Cj-Zj.
  • Variable saliente: se determina con la prueba de razón mínima, usando RHS/a_{ij} solo para coeficientes estrictamente positivos en la columna pivote.
  • Pivoteo: se normaliza la fila pivote y luego se anulan los demás coeficientes de la columna pivote mediante operaciones elementales.

5. Optimalidad y diagnósticos

  • Óptimo: no quedan valores positivos en Cj-Zj (en maximización, con esta convención).
  • Óptimos alternativos: en la tabla final, alguna variable no básica tiene costo reducido cero.
  • Degeneración: una variable básica toma valor cero o hay empates en la razón mínima.
  • No acotación: la variable entrante no tiene coeficientes positivos en su columna para aplicar la prueba de razón.
  • Infactibilidad: al terminar Fase I permanece alguna artificial positiva en la base.

6. M grande y dos fases

Cuando no existe una base factible inicial natural, se usan dos estrategias comunes:

M grande: se penalizan las variables artificiales en la función objetivo con una constante muy grande M, forzando su salida de la base.
Dos fases: en la Fase I se minimiza la suma de artificiales para encontrar una base factible; en la Fase II se optimiza la función objetivo original desde esa base.

Guía de aprendizaje paso a paso

  1. Leer cuidadosamente el modelo. Identifica si es de maximización o minimización, el tipo de restricciones y si todas las variables ya son no negativas.
  2. Transformar a forma estándar. Agrega holguras, excesos y artificiales cuando corresponda. Este paso es determinante, porque de él depende la posibilidad de construir una base inicial.
  3. Elegir el enfoque adecuado. Si todas las restricciones son \le con RHS no negativos, suele existir una base natural de holguras. Si hay \ge o igualdades, decide si conviene usar M grande o dos fases.
  4. Construir la tabla inicial. Rotula columnas y registra claramente Base, Cb, coeficientes tecnológicos y RHS.
  5. Calcular Zj y Cj − Zj. Esta fila resume la calidad de la solución actual y dirige la elección de la variable entrante.
  6. Seleccionar la variable entrante. Escoge la de mayor mejora potencial. En problemas de maximización con la convención usada aquí, se elige el mayor valor positivo en Cj-Zj.
  7. Aplicar la prueba de razón mínima. Divide RHS entre los coeficientes positivos de la columna pivote. La menor razón positiva identifica la variable saliente.
  8. Realizar el pivoteo. Convierte el pivote en 1 y los demás elementos de su columna en 0. Este paso actualiza la base y genera una nueva solución básica factible.
  9. Repetir iteraciones. En cada nueva tabla, recalcula Zj y Cj − Zj y verifica si aún existe mejora posible.
  10. Interpretar la tabla final. Extrae los valores de las variables básicas, identifica las holguras, interpreta el valor óptimo y verifica el resultado en el modelo original.
Errores frecuentes: olvidar cambiar el signo de una restricción al normalizar, usar razones con coeficientes no positivos, no actualizar Zj correctamente, o interpretar como óptima una tabla que aún tiene mejoras posibles.

La clave está en que una variable no básica asociada a una dirección factible puede tener costo reducido cero. Eso significa que existe otra base óptima distinta. En términos geométricos, el óptimo no está en un solo vértice sino en un segmento completo.

Conclusión: hay múltiples soluciones con x_1+x_2=5 y Z=10.

Buenas prácticas y errores comunes

  • Escribe siempre el modelo original antes de transformarlo: esto facilita la verificación final.
  • Usa una convención única para la fila de optimalidad (por ejemplo, siempre Cj-Zj).
  • No apliques la prueba de razón con coeficientes nulos o negativos en la columna pivote.
  • En M grande y dos fases, controla cuidadosamente la salida de artificiales.
  • Interpreta las holguras y excesos: no son solo variables técnicas, también aportan significado gerencial.
  • Si el problema parece “raro”, verifica si hay degeneración, múltiples óptimos, infactibilidad o no acotación.

Cierre de la sección

Dominar el método simplex manual es esencial porque permite comprender el corazón algorítmico de la Programación Lineal. Aunque en la práctica se usen Solver o Python, entender la lógica tabular hace posible interpretar resultados, diagnosticar problemas de formulación y seguir con rigor el razonamiento detrás del óptimo. Si ya comprendes forma estándar, construcción de base, pivoteo y casos especiales, estás listo para pasar a la automatización con Excel Solver y Python.
