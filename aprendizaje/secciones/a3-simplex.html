A3. Método Simplex manual / tabular

A1 FormulaciónA2 GráficoA3 SimplexA4 SolverA5 PythonA6 Sensibilidad

Competencia: Resolver modelos de Programación Lineal mediante el algoritmo simplex usando la metodología tabular de forma canónica, fila 0, solución básica factible, prueba de razón, operaciones elementales de fila y lectura de la tabla final.

Enfoque metodológico de esta sección

Esta versión de la sección A3 sigue la metodología tabular explicada en el capítulo 4 de Winston, Albright y otros: primero se convierte el modelo a forma estándar, luego se construye una forma canónica con una solución básica factible inicial, se escribe la función objetivo como fila 0, y se avanza de una solución básica factible a otra mediante pivotes y operaciones elementales de fila.

Convención usada en todos los ejemplos: para problemas de maximización se escribe la fila 0 como z - c_1x_1 - c_2x_2 - \cdots - c_nx_n = 0. Si en fila 0 existe algún coeficiente negativo en una variable no básica, la solución actual no es óptima. Entra la variable con el coeficiente más negativo.

Teoría del método simplex tabular

1. Forma estándar

Un modelo está en forma estándar cuando todas las restricciones son ecuaciones y todas las variables son no negativas. Para transformar restricciones:

  • Si la restricción es \le, se suma una variable de holgura s_i.
  • Si la restricción es \ge, se resta una variable de exceso e_i y, si se requiere una base inicial, se agrega una artificial a_i.
  • Si la restricción es igualdad y no contiene una variable básica natural, se agrega una artificial.

2. Forma canónica y solución básica factible

Una forma canónica tiene una variable básica por fila con coeficiente 1 en su fila y 0 en las demás. Si los lados derechos son no negativos, la tabla permite leer una solución básica factible por inspección: las variables básicas toman el RHS y las no básicas valen cero.

3. Fila 0

La función objetivo se escribe como una ecuación. Por ejemplo, Max\ z=3x_1+5x_2 se convierte en z-3x_1-5x_2=0. La fila 0 revela si aumentar una variable no básica mejora o empeora el valor de z.

4. Variable entrante

En maximización, entra la variable no básica con el coeficiente más negativo en fila 0. Esto representa la variable que aumenta más rápidamente el valor de la función objetivo.

5. Prueba de razón

Para mantener la factibilidad, se calcula RHS/a_{ij} solo en filas donde el coeficiente de la variable entrante sea positivo. Gana la menor razón no negativa. La variable básica de esa fila sale de la base.

6. Pivoteo con EROs

El pivote se transforma en 1 y todos los demás coeficientes de la columna pivote se transforman en 0. Estas son operaciones elementales de fila. Después del pivote, la variable entrante reemplaza a la saliente como básica.

7. Criterios de parada

  • Óptimo en maximización: todos los coeficientes de variables no básicas en fila 0 son no negativos.
  • No acotado: hay coeficiente negativo en fila 0, pero la columna de la variable entrante no tiene coeficientes positivos en las restricciones.
  • Óptimos alternativos: en una tabla óptima, alguna variable no básica tiene coeficiente cero en fila 0 y puede pivotarse.
  • Degeneración: una razón mínima es cero o una variable básica queda con RHS cero.
  • Infactibilidad: al terminar Fase I o M grande queda una artificial positiva.

Guía de aprendizaje paso a paso

  1. Formule el modelo original. Identifique variables, función objetivo, restricciones y dominio.
  2. Convierta a forma estándar. Use holguras, excesos y artificiales según el signo de cada restricción.
  3. Construya la fila 0. Escriba la función objetivo en forma z - c_1x_1 - ... - c_nx_n = 0 para maximización.
  4. Identifique la solución básica factible inicial. Las holguras suelen ser básicas si las restricciones son \le y los RHS son no negativos.
  5. Revise optimalidad. Si fila 0 tiene coeficientes negativos, todavía puede mejorar.
  6. Elija variable entrante. Escoja la columna con coeficiente más negativo en fila 0.
  7. Haga la prueba de razón. Calcule razón solo si el coeficiente de la columna entrante es positivo.
  8. Realice EROs. Normalice la fila pivote y elimine la variable entrante de las demás filas, incluida fila 0.
  9. Repita. Continúe hasta cumplir el criterio de optimalidad o detectar un caso especial.
  10. Interprete la solución. Lea variables básicas, no básicas, holguras, valor óptimo y restricciones activas.

Simplex básico de maximización

Planteamiento y modelo original

Max z = 3x1 + 5x2
x1 <= 4
2x2 <= 12
3x1 + 2x2 <= 18
x1,x2 >= 0

Forma estándar y fila 0

z - 3x1 - 5x2 = 0
x1 + s1 = 4
2x2 + s2 = 12
3x1 + 2x2 + s3 = 18

Forma canónica 0

La base inicial es {s1,s2,s3}. En fila 0, x2 tiene el coeficiente más negativo; por tanto entra x2. Razones: 12/2=6 y 18/2=9; sale s2.

Después del pivote en fila 2, entra x1 porque su coeficiente en fila 0 sigue siendo negativo. Razones: 4/1=4 y 6/3=2; sale s3.

PL-SEC3-EJ09

Modelo no acotado

Planteamiento y modelo original

Max z = x1 + x2
x1 - x2 <= 1
x1,x2 >= 0

Forma estándar y fila 0

z-x1-x2=0
x1-x2+s1=1

Forma canónica 0

Entra x1 por coeficiente -1. Razón: 1/1=1; sale s1.

FilaBVzx1x2s1RHS
0z1-1-100
1s101-111

Forma canónica 1

Ahora x2 tiene coeficiente negativo en fila 0, pero su columna no tiene coeficientes positivos en las restricciones. No se puede aplicar la prueba de razón.

FilaBVzx1x2s1RHS
0z10-211
1x101-111

Solución

El problema es no acotado: no existe máximo finito.

Interpretación

El diagnóstico tabular coincide con la teoría: si una variable puede mejorar z y no hay fila que limite su aumento, la función objetivo crece indefinidamente.

Verificación

Tomando x2=t y x1=t+1 se cumple la restricción y z=2t+1 crece sin límite.

Lectura final de una tabla simplex

  • Las variables básicas están en la columna BV y toman el valor RHS.
  • Las variables no básicas valen cero.
  • El valor de la función objetivo se lee en RHS de fila 0.
  • Las holguras positivas significan recursos no utilizados; holgura cero indica restricción activa.
  • Una artificial positiva al final implica que el modelo original es infactible.
