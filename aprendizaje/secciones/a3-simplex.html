A3. Método Simplex manual / tabular

A1 FormulaciónA2 GráficoA3 SimplexA4 SolverA5 PythonA6 Sensibilidad

Competencia: aplicar el método simplex tabular con forma estándar, forma canónica, fila 0, solución básica factible, prueba de razón mínima y operaciones elementales de fila.

Enfoque metodológico de la sección

Esta sección usa la metodología tabular clásica del capítulo de Winston et al.: convertir el modelo a forma estándar, obtener una solución básica factible inicial, escribir la función objetivo como fila 0, seleccionar la variable entrante, aplicar la prueba de razón mínima, pivotear con operaciones elementales de fila y repetir hasta obtener una forma canónica óptima.

Convención de esta sección: para problemas de maximización se usa la fila 0 con la forma z − c1x1 − c2x2 − ··· − cnxn = 0. Mientras exista un coeficiente negativo en fila 0 asociado a una variable no básica, la solución actual puede mejorar.

Teoría del método simplex tabular

1. Modelo general en forma original

Un problema de maximización lineal puede escribirse de forma compacta así:

Maximizar z = c1x1 + c2x2 + ··· + cnxn
sujeto a a11x1 + a12x2 + ··· + a1nxn ≤ b1
a21x1 + a22x2 + ··· + a2nxn ≤ b2
⋮
xj ≥ 0,   j = 1,2,…,n

El método simplex necesita que todas las restricciones estén escritas como ecuaciones y que todas las variables sean no negativas.

2. Conversión a forma estándar

La forma estándar transforma las desigualdades en ecuaciones:

Restricción ≤ ai1x1 + ··· + ainxn + si = bi,   si ≥ 0
Restricción ≥ ai1x1 + ··· + ainxn − ei = bi,   ei ≥ 0
Con artificial ai1x1 + ··· + ainxn − ei + ai = bi,   ai ≥ 0

Las variables de holgura miden recurso no usado; las variables de exceso miden cuánto se supera un mínimo; las artificiales solo sirven para iniciar el algoritmo cuando no hay base natural.

3. Fila 0 de la función objetivo

La función objetivo se lleva a la tabla como una ecuación. Por ejemplo:

Original Max  z = 3x1 + 5x2
Fila 0 z − 3x1 − 5x2 = 0

En maximización, un coeficiente negativo en fila 0 indica que aumentar esa variable no básica puede incrementar z.

4. Forma canónica y solución básica factible

Una tabla está en forma canónica si cada fila de restricción tiene una variable básica con columna identidad. Si el lado derecho es no negativo, se lee una solución básica factible por inspección:

BV variables básicas = valores RHS
NBV variables no básicas = 0

5. Variable entrante, prueba de razón y variable saliente

Para maximización con fila 0 en la forma usada aquí:

Entrante variable no básica con el coeficiente más negativo en fila 0
Razón θi = biaij,   solo si aij > 0
Saliente variable básica de la fila con menor θi ≥ 0

Si la columna de la variable entrante no tiene coeficientes positivos en las restricciones, no hay variable saliente y el problema es no acotado.

6. Pivoteo con operaciones elementales de fila

Después de escoger el pivote, se aplican EROs para que la columna de la variable entrante se convierta en una columna identidad:

Paso 1 Fila pivote nueva = Fila pivote antiguaelemento pivote
Paso 2 Fila k nueva = Fila k antigua − (coeficiente en columna pivote) × Fila pivote nueva

El proceso se repite, incluida la fila 0, hasta que se cumpla el criterio de optimalidad.

7. Criterios de parada

  • Óptimo en maximización: todos los coeficientes de variables no básicas en fila 0 son no negativos.
  • No acotado: hay coeficiente negativo en fila 0, pero la columna entrante no tiene coeficientes positivos en las restricciones.
  • Óptimos alternativos: una variable no básica tiene coeficiente cero en una tabla óptima y puede entrar a la base.
  • Degeneración: alguna variable básica tiene RHS igual a cero o la prueba de razón tiene empate con valor cero.
  • Infactibilidad: en Fase I queda un valor óptimo positivo de la suma de artificiales, o una artificial positiva permanece indispensable.

Guía de aprendizaje paso a paso

  1. Formular el modelo original. Defina variables, función objetivo, restricciones y dominio.
  2. Convertir a forma estándar. Agregue holguras, excesos y artificiales cuando corresponda.
  3. Escribir la fila 0. Para maximización use z − c1x1 − ··· − cnxn = 0.
  4. Construir la tabla canónica inicial. Identifique variables básicas y no básicas.
  5. Leer la solución básica factible inicial. Variables básicas = RHS; variables no básicas = 0.
  6. Seleccionar variable entrante. Use el coeficiente más negativo en fila 0.
  7. Aplicar la prueba de razón. Calcule bi/aij solo si aij > 0.
  8. Pivotear. Haga 1 el pivote y 0 el resto de la columna usando EROs.
  9. Repetir. Continúe hasta que fila 0 no tenga coeficientes negativos.
  10. Interpretar. Reporte solución, valor óptimo, holguras, restricciones activas y diagnóstico del caso.

Lectura final de una tabla simplex

  • Las variables básicas están en la columna BV y toman el valor RHS.
  • Las variables no básicas valen cero.
  • El valor de la función objetivo se lee en RHS de fila 0.
  • En maximización, si fila 0 no tiene coeficientes negativos en variables no básicas, la solución es óptima.
  • Una holgura positiva significa recurso no utilizado; holgura cero significa restricción activa.
