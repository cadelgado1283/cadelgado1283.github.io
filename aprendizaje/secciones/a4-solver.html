A4. Resolver modelos de Programación Lineal con Excel Solver

A1 FormulaciónA2 GráficoA3 SimplexA4 SolverA5 PythonA6 Sensibilidad

Competencia: construir modelos lineales en hoja de cálculo, configurar Solver con método Simplex LP, interpretar solución, restricciones, holguras y reportes básicos.

Teoría ampliada: ¿cómo piensa Solver?

Solver no reemplaza la formulación matemática; la ejecuta. El estudiante debe traducir el modelo a una estructura de Excel donde las celdas variables representan las decisiones, la celda objetivo calcula la función objetivo mediante fórmulas, y las celdas de restricciones calculan los lados izquierdos de las restricciones. Para Programación Lineal continua se debe usar Simplex LP.

Estructura lógica

Decisiones → fórmulas de consumo / aporte → función objetivo → restricciones → solución óptima

Función objetivo típica

Z = SUMPRODUCT(coeficientes_objetivo, celdas_variables)

Restricción típica

LHS_i = SUMPRODUCT(coeficientes_restricción_i, celdas_variables) ≤, = o ≥ RHS_i

Guía detallada paso a paso

  1. Formule primero en papel: defina variables, FO, restricciones y dominio.
  2. Diseñe la matriz: ubique variables en una fila o columna y parámetros en tablas limpias.
  3. Calcule la FO: use SUMPRODUCT para evitar fórmulas largas y errores.
  4. Calcule cada restricción: una celda por lado izquierdo, una celda para el sentido y una para RHS.
  5. Abra Solver: Datos → Solver. Si no aparece, active el complemento desde Opciones → Complementos.
  6. Configure objetivo: seleccione la celda objetivo y elija Max, Min o Value Of.
  7. Configure variables: seleccione las celdas de decisión.
  8. Agregue restricciones: vincule LHS con RHS, añada no negatividad o marque “Make Unconstrained Variables Non-Negative”.
  9. Elija método: use Simplex LP para modelos lineales.
  10. Resuelva e interprete: revise estado, solución, restricciones activas, holguras y reportes.
Advertencia: si el modelo es lineal pero selecciona GRG Nonlinear, puede obtener resultados innecesariamente lentos o confusos. Para PL use Simplex LP.

Buenas prácticas en Excel Solver

  • Nombres claros para rangos: Variables, Utilidad, Consumo, Disponibilidad.
  • Una sola tabla de coeficientes para evitar duplicar datos.
  • Separar datos, modelo y resultados.
  • Bloquear fórmulas y resaltar celdas variables.
  • Verificar que toda fórmula dependa directa o indirectamente de las variables.
  • Revisar unidades: horas, kg, unidades, pesos, porcentajes.
  • Solicitar reporte de sensibilidad solo si el modelo es lineal continuo y Solver encontró óptimo.

PL-SEC4-EJ01

Producción básica

Planteamiento. Mesas y sillas usan carpintería y pintura. El objetivo del estudiante es construir la hoja, configurar Solver, obtener la solución e interpretar restricciones activas y holguras.

Modelo matemático

Max Z = 50 mesas + 30 sillas
Restricciones lineales de capacidad, cobertura o balance según el contexto.
Dominio: variables ≥ 0.

Diseño recomendado en Excel

ElementoImplementación sugerida
Celdas variablesRango resaltado en amarillo con las decisiones del modelo.
Función objetivo=SUMPRODUCT(coeficientes, variables)
Lado izquierdo restricciones=SUMPRODUCT(fila_coeficientes, variables)
RHSDatos fijos: disponibilidad, demanda, presupuesto o requerimientos.

Configuración Solver

  • Set Objective: celda que calcula la FO.
  • To: Max o Min según corresponda.
  • By Changing Variable Cells: rango de variables.
  • Subject to Constraints: agregue cada LHS con su sentido y RHS.
  • Solving Method: Simplex LP.

Procedimiento detallado

  1. Verifique que la celda objetivo cambie al modificar manualmente las variables.
  2. Confirme que las restricciones calculen consumos o aportes reales.
  3. Agregue no negatividad para todas las variables.
  4. Ejecute Solver y conserve la solución.
  5. Solicite reporte de respuesta y, si aplica, reporte de sensibilidad.

Resultado e interpretación

Mesas=20, Sillas=0 si se prioriza rentabilidad por recursos en el ejemplo de capacidad proporcional; si se usa el modelo clásico con utilidades 50 y 30 y restricciones proporcionales puede haber múltiples soluciones.

Verificación

Revise si las restricciones son proporcionales: esto afecta unicidad del óptimo. Además, cambie temporalmente alguna variable para comprobar que las fórmulas reaccionan correctamente.
