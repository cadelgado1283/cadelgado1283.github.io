A4. Resolución con Excel Solver

A1 FormulaciónA2 GráficoA3 SimplexA4 SolverA5 PythonA6 Sensibilidad

Competencia: Configurar modelos lineales en Excel Solver con fórmulas transparentes, restricciones correctas e interpretación de reportes.

Guía de aprendizaje

  • Diseñar una hoja con datos, variables, cálculos y restricciones.
  • Usar SUMPRODUCT para objetivo y recursos.
  • Configurar Solver con Simplex LP.
  • Agregar restricciones de no negatividad y límites.
  • Generar e interpretar resultados y reportes.
  • Auditar fórmulas antes de confiar en la solución.

Buenas prácticas y errores comunes

  • No escribir valores fijos donde deben ir fórmulas.
  • No seleccionar GRG Nonlinear para PL continua.
  • No olvidar marcar no negatividad.
  • El reporte de sensibilidad aplica a modelos lineales continuos, no a enteros.

PL-SEC4-EJ01

Producción básica en Solver

Planteamiento

El estudiante debe montar el modelo en Excel usando fórmulas vinculadas a las celdas variables y resolverlo con el método Simplex LP.

Datos

Elemento SolverConfiguración
Celdas variablesB2:C2
Celda objetivoD4
RestriccionesD6<=80, D7<=40
MétodoSimplex LP
Resultado esperadox1=20, x2=60, Z=2600

Variables de decisión

Las celdas variables contienen las cantidades de decisión. Deben iniciar con valores no negativos, por ejemplo 0 o 1.

Función objetivo

La celda objetivo se calcula con SUMPRODUCT entre coeficientes económicos y celdas variables.

Restricciones

Cada lado izquierdo se calcula con SUMPRODUCT. Luego Solver compara esas celdas contra disponibilidades, demandas o requerimientos.

Dominio

Agregar restricción de no negatividad. Usar enteras únicamente si el problema exige cantidades indivisibles.

Método / procedimiento

  • Organizar datos en tabla: coeficientes, recursos y límites.
  • Crear celdas variables.
  • Calcular función objetivo con =SUMPRODUCT(...).
  • Calcular uso de recursos con =SUMPRODUCT(...).
  • Abrir Datos > Solver y seleccionar Simplex LP.
  • Generar reporte de sensibilidad si el modelo es lineal continuo.

Solución

Solución esperada: x1=20, x2=60, Z=2600.

Interpretación

La solución debe leerse en unidades del problema: productos, mezclas, anuncios, turnos o envíos. No basta reportar el valor objetivo; se debe explicar la decisión.

Verificación

Cambiar manualmente algunos valores de las variables y revisar que la celda objetivo y las restricciones cambien correctamente.
